# 持续心跳与额度口径

需要持续在线时，在对应Windows私有包运行4-开启持续在线检测.cmd。它先验证设备Key和目录，将心跳工具复制到当前用户私有设备目录，用已有pythonw启动后台进程，并在当前用户Startup写入单一快捷方式。无需管理员权限、不设置系统服务，不自动升级Python或更改主Codex。

程序每30秒发送真实心跳，即使没有对话也发送。仅报告是否存在Codex/ChatGPT进程，不上传进程列表、窗口标题或文件内容。单设备文件锁防多开；断网不伪造成功。回执presence-status.json不含Key。关机、睡眠和断网造成120秒超时是正常状态。

5-停止持续在线检测.cmd请求停止本次后台心跳，下次用户登录仍启动；6-移除持续在线检测.cmd同时移除登录启动。它们只针对本设备组件，不结束Codex、不撤销Key、不删除配置。网络请求正在超时时停止可能需等待本次请求超时；服务端不会因此收到假心跳。

先核对目标机Python3.9+及pythonw.exe，再安装；已有兼容Codex++不强制升级。Mac环境只能验证逻辑和打包，不能宣称Windows Startup/ACL实测通过。缺少权限或组件时报告真实缺口，不改为系统管理员常驻或计划任务绕过策略。

管理员验收须观察真实心跳、空闲时持续在线、Codex退出后的运行状态、停止超过120秒离线以及移除后登录不重启。先前3-在线测试仍为5分钟限时，不代表4已安装。

账户官方剩余由主模型源通过account/rateLimits/read读取，不把OAuth给子设备。设备Token来自最终usage；本地account/usage/read活动统计实测受本地会话库影响，未验证其跨设备完整性，不当作全账户总量。账户总分母不可验证时显示不可计算；官方配额百分比也不能直接按设备Token比例分摊。
