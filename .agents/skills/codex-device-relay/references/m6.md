# M6 不在身边时的远程试点

可通过已有受信远程入口操作，不要求人在机器旁边；但Skill不会使远程设备自动运行，也不会开启SSH或取得系统登录权限。

## 已有通道

**M6已有可用Codex会话**：让该设备Codex安装Skill并在M6本地执行客户端路线。它须先有可用模型连接；保留旧模型接入，等新入口通过再切换，避免切断安装任务。

**主管用普通SSH操作M6**：需要实际macOS短用户名、允许的远程账号、已验证SSH主机指纹和可用登录方式。用BatchMode及严格主机密钥校验，验证身份后先只读盘点系统/Tailscale/Codex++/当前会话。不猜用户名，不关闭校验，不复制主账户OAuth代替认证。

SSH可以复制Skill和运行probe；Codex++新供应商与多开窗口可能仍需要已登录图形会话及允许的界面工具。屏幕共享端口开放也不等于已有登录权限。

## 2026-10-15状态基线

- M4与M6已在同一Tailscale私网显示在线，主机模型仅本机入口通过验收。
- 最近主管探测M6的TCP22、5900可连接，较早“端口拒绝”记录已过时。
- 主管用严格校验连接M6时没有已知SSH主机密钥，故在身份校验前停止；未完成SSH认证或远程安装。
- 私网模型发布、M6设备Key和M6端到端任务仍待验收。

公开版不记录实际IP、DNS、SSH用户名、主机指纹、Key或私有路径。

3. M6先probe认证/目录，再一次真实流式。
4. M6新增纯API供应商和独立多开，读取本地测试文件、多轮工具及业务插件验收。
5. 测试单台撤销、原主管仍正常并记录回滚。

无远程身份或登录权限时继续准备与发布材料，M6保留待验收，不假报已配置，也不要求用户必须回到机器旁。
