# 亚马逊多账户产品日级 CPO 自动整理 SOP 更新日志

本日志区分“已发布基线”和“已确认待发布改动”。未正式写入新版 SOP 的规则不会冒充现行规则。

## [Unreleased] 下一版本

### 已确认待合入

- **当日有效产品范围**：由“SKU 表中该运营全部唯一款式”调整为“当前运营 SKU 白名单 ∩ 本轮业务报告实际匹配产品”，再剔除用户明确排除项。SKU 表负责身份，不代表当天一定要计算。
- **流媒体正式六分类**：广告费用、广告单量、平均费用/单统一按“手动 → 自动 → 头条 → 视频 → 展示 → 流媒体”排列；总费用和总广告单必须包含流媒体；增加“流媒体不得重复计入视频”的专项校验。
- **默认输出模板升级**：V3.4 的 27 列口径升级为 28 个有效字段；流媒体从尾部备注位置移入三组广告字段，并增加流媒体平均费用/单。
- **固定等分规则**：`ZJ1-W85816351 头条 target W882 1.9` 的费用与广告单量固定在 W85男、W81男、W63男、W51男四款之间等分，不受推广 ASIN/SKU 明细影响。建议新增 `fixed_equal_split`，或用明确的 `manual_confirmed` 规则表达。
- **广告单量原始字段**：为复现现有人工表口径，广告单量应统一取报告中的“已售商品数量”，不再默认使用“购买量”。
- **日期识别**：必须区分广告明细日期、业务报告数据日期和文件导出日期；不得仅凭文件名日期推断业务日期，广告报告必须按明细日期精确筛选。
- **新特殊 Campaign 门槛**：同时命中多个产品、但规则表未登记的 Campaign，不得自行创建永久规则并直接输出最终 CSV；应先回显 Campaign、建议归属和影响范围，确认后再入规则表。
- **校验升级**：五类费用/单量守恒校验升级为六类，并同步修订产品数量校验，避免把当天无业务记录的 SKU 表款式强制输出。

### 暂不固化

- `ZJ1-W75V2 Z32 头条 +Water Shoes大词 6.12` 暂不写成永久归属规则。已观察到某日费用与广告单落在 Z32 推广商品，但“按推广商品拆分”还是“整条归 W75V2”仍需运营最终确认。

### 验证记录

- 2026-08-29 重算中，标准五类广告费与人工汇总仅相差约 0.04 美元，说明日期、账户和费用归属框架基本对齐。
- 流媒体纳入后总广告费为 9,452.28 美元。
- `W85816351` 恢复固定四等分后，W85、W81、W63、W51男与人工费用结果基本一致。
- 费用侧基本校准后，主要剩余差异集中在广告单量字段口径和个别 Campaign 的业务归属确认。

## [V3.4] - 2026-08-30

### 新增

- 多运营共享账户强制加载《运营 SKU 产品表》。
- 运营身份成为固定执行入口。
- 内部产品主键改为 `运营小组|款式`。
- 默认从 SKU 表自动读取当前运营负责的全部款式，不再固定询问产品清单。
- 增加“运营 / 产品代号 / 业务账户 / 广告账户 / 父 ASIN”五列映射强制回显门槛。
- 增加广告数据运营隔离层和跨运营串数校验。

### 调整

- 日期可从报表唯一识别时自动采用，仅在冲突或缺失时询问。
- 男女款和版本优先通过当前运营的 SKU/ASIN 白名单自动区分。
- 最终 CSV 产品代号保持 SKU 表中的原始款式名，不擅自追加男/女或运营后缀。
- Campaign 规则只能在运营与产品身份锁定后执行，不能重新并入其他运营的同款数据。
- 文件引导改为先检查已有文件，只提示实际缺失的必要报告。

## [V3.3] - 历史版本

### 新增与调整

- 固化 `campaign_code`、`advertised_product`、`mixed_split`、`manual_confirmed` 四种 Campaign 归属方式。
- 已确认特殊 Campaign 通过规则表复用，新特殊 Campaign 才询问一次。
- 混合 Campaign 有商品明细时精确拆分，无明细时按白名单等分。
- `AUTO / 自动` 优先归入 SP 自动，避免被“广泛”等命名词误分到手动。
- 增加 Campaign 级费用与广告单量守恒校验。

## 维护说明

- “Unreleased”仅表示业务复盘已确认、等待正式升级 SOP 的规则。
- 每次发布新版 SOP 时，将对应条目移动到正式版本区，并补充发布日期。
- 原始报表、SKU 明细、账户凭据及运营敏感数据不得写入本日志。
