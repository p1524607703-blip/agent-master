# 亚马逊FBA重量和尺寸重新测量申请SOP

> [!summary] 摘要
> 本 SOP 将 Amazon Seller Central 的“重量和尺寸相关问题”申请标准化为可由影刀在紫鸟浏览器内执行的单品流程，覆盖 FNSKU 输入、问题类型选择、资格判断、测量原因、包装类型、继续申请、结果核验和异常留痕。任何流程只有读取到明确成功提示或工单编号后，才能记录为成功。

## 核心知识

- **目标**：针对 Amazon FBA 商品包装重量或尺寸测量不准确的情况，请求重新测量，并在符合条件时申请赔偿亚马逊物流配送费用。
- **当前生产环境**：macOS + 紫鸟浏览器 + 影刀；按用户确认，当前实际生产适配以影刀为准。
- **处理单位**：一次只处理一个“店铺 + 站点 + FNSKU”，批量任务按输入表逐行循环。
- **资格原则**：以页面明确显示“您有资格提交此请求”为唯一放行条件，不自行根据页面上的月度次数计算资格。
- **成功原则**：点击“继续”不等于提交成功；必须读取成功提示、请求编号或工单编号，并保存证据。
- **防重原则**：同一店铺、站点、FNSKU、申请类型和自然月建立唯一任务键，状态未知时禁止自动重复提交。

## 适用范围与固定业务口径

### 适用范围

- Amazon Seller Central 已登录且店铺、站点正确。
- 目标商品有有效 FNSKU。
- 商品的 FBA 包装重量或尺寸疑似被 Amazon 错误测量。
- 需要发起“重新测量和赔偿亚马逊物流配送费用”请求。

### 当前截图对应的默认选择

| 字段 | 默认值 | 是否允许参数化 |
|---|---|---|
| 问题类型 | 重新测量和赔偿亚马逊物流配送费用 | 否，本流程固定 |
| 是否有自己的重量和尺寸数据 | 否 | 是 |
| 测量请求原因 | 尽管我的包装没有变化，亚马逊的商品测量值却不正确了 | 是 |
| 包装类型 | 塑料袋（聚乙烯塑料袋和防静电袋等） | 是，必须与实物一致 |

> [!warning] 不得为通过流程而填写错误信息
> “是否有自己的测量数据”“测量请求原因”和“包装类型”必须与商品实际情况一致。截图中的选项只是当前默认业务口径，不适用于所有 FNSKU。

## 输入数据规范

影刀任务启动前读取一张输入表，至少包含以下字段：

| 字段 | 必填 | 示例或默认值 | 校验规则 |
|---|---:|---|---|
| `store_name` | 是 | US-WHITIN | 必须能唯一定位紫鸟店铺 |
| `marketplace` | 是 | US | 打开申请页后再次核对站点 |
| `fnsku` | 是 | X003VS75V1 | 去除首尾空格，不得为空 |
| `has_own_measurement` | 是 | `false` | `true` 或 `false` |
| `request_reason` | 是 | `amazon_value_incorrect_unchanged_package` | 必须映射到页面真实选项 |
| `package_type` | 是 | `polybag` | 必须映射到页面真实包装类型 |
| `task_month` | 是 | 2026-08 | 用于防重复提交 |
| `operator_note` | 否 | 包装无变化 | 仅用于日志，不填入页面 |

### 包装类型映射

| 输入值 | 页面选项 |
|---|---|
| `polybag` | 塑料袋（聚乙烯塑料袋和防静电袋等） |
| `bubble_wrap` | 气泡膜包装 |
| `rigid_container` | 硬容器（例如塑料箱、纸板箱或塑料瓶） |
| `unpackaged` | 无外包装，商品裸露 |
| `other` | 其他 |

## 执行前检查

1. 紫鸟浏览器已打开目标店铺环境。
2. Amazon Seller Central 登录状态正常，无验证码、扫码或二次验证阻塞。
3. 页面显示的店铺和站点与输入表一致。
4. 输入表中 FNSKU、包装类型、测量原因已由运营确认。
5. 历史日志中不存在相同任务唯一键的 `SUCCESS` 或 `SUBMIT_UNKNOWN` 记录。
6. 截图目录和运行日志目录可写。

## 标准操作流程

| 步骤 | 影刀动作 | 元素识别建议 | 放行条件 | 异常处理 |
|---:|---|---|---|---|
| 1 | 在目标紫鸟店铺中打开“重新测量 FBA”收藏页，或进入重量和尺寸问题页面 | 优先使用固定 URL 路径 `/help/hub/solution/WF_FBAWeightAndDimensionsIssues`；其次使用收藏名称 | 页面标题或主标题包含“重量和尺寸相关问题” | 未登录则转人工；页面不存在记 `PAGE_CHANGED` |
| 2 | 在“输入 FNSKU”输入框填写当前行 `fnsku` | 按标签“输入 FNSKU”定位，不使用绝对坐标 | 输入框回读值与原始 FNSKU 完全一致 | 回读不一致时清空重填一次，仍失败则停止该行 |
| 3 | 点击“下一页” | 按按钮文本和角色定位 | 页面发生跳转且出现问题类型选项 | 只读动作最多重试两次 |
| 4 | 选择“重新测量和赔偿亚马逊物流配送费用” | 按完整可见文本定位对应单选框 | 单选框状态为已选中 | 选项缺失记 `PAGE_CHANGED` |
| 5 | 点击“下一页” | 按按钮文本和角色定位 | 页面出现 FNSKU 详情和资格信息 | 加载超时后刷新一次，仍失败则停止 |
| 6A | 读取并保存 FNSKU、Amazon 当前包装尺寸、包装重量、当月提交数量、页面显示上限和资格文案 | 从标签邻近文本提取，不依赖固定位置 | 页面明确显示“您有资格提交此请求” | 显示不符合资格时记 `NOT_ELIGIBLE`，不得继续 |
| 6B | 根据 `has_own_measurement` 选择“否”或“是” | 按问题“您是否有自己商品的重量和尺寸数据？”下的按钮文本定位 | 选择结果与输入参数一致 | 选择“是”后若出现截图未覆盖的新字段，记 `NEED_MANUAL` |
| 6C | 选择测量请求原因 | 默认选择“尽管我的包装没有变化，亚马逊的商品测量值却不正确了” | 对应单选框已选中 | 页面选项与输入原因无法映射时停止 |
| 7 | 点击“下一页” | 按按钮文本和角色定位 | 页面出现包装类型列表 | 页面未变化时最多重试一次 |
| 8 | 根据 `package_type` 选择准确包装类型 | 按完整可见文本定位单选框 | 页面选项与输入参数一致且已选中 | 无匹配项记 `NEED_MANUAL`，不得猜测 |
| 9 | 点击“下一页” | 按按钮文本和角色定位 | 页面出现“继续”按钮及说明文字 | 页面未变化时最多重试一次 |
| 10 | 点击“继续” | 按按钮文本和角色定位 | 进入后续申请或确认页面 | 不得把本动作直接记录为成功 |
| 11 | 核验并完成后续页面 | 读取按钮、确认文本、成功提示和请求编号 | 读取到明确成功提示或请求/工单编号 | 若出现截图未覆盖的最终提交按钮，暂停并保存截图；规则确认前记 `NEED_MANUAL` |
| 12 | 写入结果和证据 | 保存资格页、最终页截图及关键字段 | 日志写入成功且状态明确 | 结果不明确时记 `SUBMIT_UNKNOWN`，禁止自动重试 |

> [!warning] 截图未覆盖最终提交页
> 现有 6 张截图只覆盖到步骤 10 的“继续”。步骤 11 必须在实际页面首轮试运行中确认。未确认最终页面结构前，影刀应在出现新的“提交/Submit/确认”按钮时暂停，由人工审核后再补充自动化规则。

## 资格判断规则

| 页面状态 | 自动化动作 | 结果状态 |
|---|---|---|
| 明确显示“您有资格提交此请求” | 继续流程 | `ELIGIBLE` |
| 明确显示不符合资格、超过限制或不可提交 | 停止该 FNSKU | `NOT_ELIGIBLE` |
| 次数数字看似异常，但页面明确显示有资格 | 保存截图并继续 | `ELIGIBLE_WITH_WARNING` |
| 没有明确资格文案 | 停止并转人工 | `NEED_MANUAL` |

截图示例中出现“本月提交数量 99”“一个月内最多 50”同时又显示“您有资格提交此请求”。因此自动化不得自行比较 `99 > 50` 后否决，也不得忽略异常；应以资格文案放行，同时保存页面证据。

## 影刀元素识别与稳定性要求

1. 优先顺序：可访问性标签/字段标签 → 完整可见文本 → 稳定 DOM 属性 → 相对图像识别。
2. 禁止把截图中的绝对坐标作为唯一定位方式。
3. 每次导航后等待目标标题或关键控件出现，再执行下一步。
4. 每次单选后回读“已选中”状态，禁止只点击不校验。
5. FNSKU 输入后必须回读并逐字符比较。
6. 页面读取、导航等可逆动作最多重试两次。
7. “继续”“提交”“确认”等可能产生请求的动作不得盲目重试。
8. Amazon 页面文案变化或出现未知页面时立即停止当前 FNSKU，不尝试猜测相似按钮。

## 防重复与批量控制

### 任务唯一键

`store_name + marketplace + fnsku + request_type + task_month`

### 批量处理规则

1. 一次只提交一个 FNSKU。
2. 每个 FNSKU 完成后返回入口页，重新校验店铺和站点。
3. `SUCCESS`：同月不再自动执行。
4. `SUBMIT_UNKNOWN`：禁止重试，必须人工检查 Seller Central 请求记录。
5. `NOT_ELIGIBLE`：记录页面原因，不在同一批次重试。
6. `PAGE_CHANGED` 或 `NEED_MANUAL`：保留截图，继续下一条前由配置决定是否暂停整个批次。

## 输出与日志规范

| 字段 | 说明 |
|---|---|
| `run_id` | 本次影刀运行唯一编号 |
| `store_name` / `marketplace` | 实际执行店铺与站点 |
| `fnsku` | 当前商品 FNSKU |
| `amazon_dimensions` | 页面读取的 Amazon 包装尺寸 |
| `amazon_weight` | 页面读取的 Amazon 包装重量 |
| `monthly_submitted_count` | 页面显示的本月提交数量 |
| `monthly_displayed_limit` | 页面显示的月度上限 |
| `eligibility_text` | 完整资格文案 |
| `selected_reason` | 实际选中的测量原因 |
| `selected_package_type` | 实际选中的包装类型 |
| `request_id` | 成功页返回的请求或工单编号，没有则为空 |
| `status` | 标准状态码 |
| `error_message` | 页面或影刀的原始错误摘要 |
| `evidence_paths` | 资格页和最终页截图路径 |
| `started_at` / `finished_at` | 开始和结束时间 |

### 标准状态码

- `SUCCESS`：存在明确成功提示或请求编号。
- `NOT_FOUND`：FNSKU 无效或页面找不到商品。
- `NOT_ELIGIBLE`：页面明确不允许提交。
- `LOGIN_REQUIRED`：登录、验证码或二次验证阻塞。
- `PAGE_CHANGED`：页面结构或关键文案发生变化。
- `NEED_MANUAL`：进入未覆盖分支或信息不足。
- `SUBMIT_UNKNOWN`：执行了可能提交的动作，但无法确认结果。
- `FAILED`：其他明确失败。

## 验收标准

- [ ] 可在正确紫鸟店铺和 Amazon 站点打开目标页面。
- [ ] FNSKU 输入后能回读校验。
- [ ] 问题类型、原因和包装类型均按文本定位并校验选中状态。
- [ ] 不符合资格时不会继续。
- [ ] 次数数字异常时能保存证据，并以明确资格文案决策。
- [ ] 未知最终提交页会暂停，不会误点。
- [ ] 成功时能保存成功提示或请求编号。
- [ ] 状态未知时不会自动重复提交。
- [ ] 每个 FNSKU 都有资格页和最终页证据。
- [ ] 批量日志可追溯到店铺、站点、FNSKU 和运行编号。

## 待首轮实测确认

1. 点击步骤 10“继续”后的完整页面结构。
2. 最终提交按钮的准确文本及是否还有确认弹窗。
3. 成功页的固定文案和请求/工单编号字段。
4. 选择“是，我有自己的重量和尺寸数据”后新增的字段及单位。
5. Amazon 页面是否会按站点或语言切换按钮文本。
