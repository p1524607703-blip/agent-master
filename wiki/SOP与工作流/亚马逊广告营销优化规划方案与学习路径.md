# 亚马逊广告营销优化规划方案与学习路径

> [!summary] 摘要
> 本页归档飞书文档《亚马逊广告营销优化规划方案与学习路径》的本地版本，目标是先从 AMS 广告数据分析入手，建立可复用的 AI 广告诊断模板；短期掌握广告报表和评价规则，中期接入飞书表格与 `lark-cli` 做 AI 辅助分析，后期再扩展到 AMC、广告 API、用户行为分析和素材效果回流。

## 核心知识

### 当前阶段判断

当前不建议一开始就追求完整的自动化广告投放系统。更稳妥的路线是先理解广告数据、广告结构和优化动作，拿 Y10/Y11 等有投放数据的产品做练手样本，建立第一版人工可验证的分析框架。

| 阶段 | 核心目标 | 主要产出 |
|---|---|---|
| 短期 | 看懂 AMS 广告报表，判断广告活动、关键词、搜索词表现 | 广告数据字段表、评价规则、诊断模板 |
| 中期 | 建立 AI 辅助优化流程，给出否定词、预算、出价、暂停建议 | 飞书广告分析表、自动化分析提示词、周报模板 |
| 后期 | 研究 AMC、广告 API、用户行为路径和素材效果回流 | AMC 学习笔记、API 可行性评估、广告策略知识库 |

### 总目标

- 用广告数据判断哪些广告值得继续投，哪些应该暂停或优化。
- 识别浪费预算的无效搜索词，并生成否定词建议。
- 判断关键词、商品投放、广告活动是否需要加预算、降价、提价或观察。
- 把广告优化动作标准化，让 AI 能基于飞书表格数据输出可复核建议。
- 最终把广告数据和视频素材研究连接起来，判断什么素材真正带来更好的转化。

### 学习路径

#### 第 1 阶段：广告基础概念

目标：先把广告后台的语言听懂，避免直接看数据时不知道指标含义。

| 学习重点 | 必须掌握的问题 | 输出物 |
|---|---|---|
| 广告类型 | SP、SB、SD 分别适合什么目标？ | 广告类型对照表 |
| 投放结构 | Campaign、Ad Group、Keyword、Search Term、ASIN Targeting 的关系是什么？ | 广告结构图 |
| 匹配类型 | 精准、词组、广泛匹配分别怎么影响流量质量？ | 匹配类型判断表 |
| 核心指标 | CTR、CVR、CPC、ACOS、ROAS、Spend、Sales、Orders 各说明什么？ | 指标解释卡片 |

#### 第 2 阶段：报表与字段

目标：明确运营需要导出哪些数据，AI 才能分析广告。

| 报表 | 用途 | 重点字段 |
|---|---|---|
| 广告活动报表 | 判断整体投放效率和预算分配 | Campaign、Spend、Sales、Orders、ACOS、ROAS、CTR、CVR |
| 搜索词报表 | 发现真实用户搜索意图和无效词 | Customer Search Term、Clicks、Spend、Orders、Sales、ACOS |
| 关键词报表 | 判断关键词是否要加价、降价、暂停 | Keyword、Match Type、Bid、CPC、CTR、CVR、ACOS |
| 商品投放报表 | 判断 ASIN 定向和竞品投放效果 | Targeting、Advertised SKU、ASIN、Spend、Sales、Orders |
| 已购商品报告 | 判断广告最终带来的实际购买产品 | Purchased ASIN、Advertised ASIN、Sales、Orders |

#### 统一报告的时间维度选择（分时投放）

Amazon Ads 新统一报告中的时间字段用于决定结果如何分组，不用于设置报告查询范围；查询范围需要在报告周期中另外选择。

| 时间维度 | 输出示例 | 适用问题 | 分时投放建议 |
|---|---|---|---|
| 日期（Date） | 2026-07-19 | 每个自然日表现如何 | 与小时一起选，用于检查各日小时规律是否稳定 |
| 周（Week） | 2026-W29 | 每个自然周总体表现如何 | 不用于一天内分时 |
| 月中的一天（Day of month） | 1–31 | 每月第几天表现如何 | 只适合月初、发薪日等周期研究 |
| 月（Month） | 2026-07 | 月度趋势 | 不用于一天内分时 |
| 年份（Year） | 2026 | 年度趋势 | 不用于一天内分时 |
| 一周中的某一天（Day of week） | 周一至周日 | 星期规律如何 | 可选；若与小时组合受限，可从日期在表格中派生星期 |
| 小时（Hour） | 00–23 时 | 一天内哪个小时流量和转化最好 | 必选 |
| 日期范围（Date range） | 2026-07-01 至 2026-07-14 | 整个所选区间汇总 | 不用于小时分析 |

分时投放的推荐组合是 `日期 + 小时 + 广告活动`。导出后分别制作“按小时汇总”和“星期 × 小时”透视表，使用 Impressions、Clicks、Cost、Purchases、Sales、Purchase rate over clicks、ROAS/ACOS 判断流量高峰与高价值时段。只看最佳流量时间时，Clicks 代表实际广告访问高峰；用于调整竞价时，还必须同时满足转化率和 ROAS/ACOS 要求。

> [!warning] 重复“日期”字段
> 界面中第一个不带展开箭头的“日期”是具体自然日期。带展开箭头的“日期”是字段分组，下面包含“月中的一天”等派生维度；不要为了分时分析勾选整个分组。

#### 第 3 阶段：广告评价规则

目标：把“广告好不好”拆成可执行判断，而不是凭感觉。

| 广告表现 | 可能原因 | 建议动作 |
|---|---|---|
| 有点击无订单，花费持续增加 | 搜索意图不匹配、页面转化弱、价格或评价劣势 | 加否定词、降价、暂停观察 |
| CTR 高但 CVR 低 | 素材或标题吸引点击，但详情页承接不够 | 检查 Listing、A+、价格、评论和主图 |
| CVR 好但曝光少 | 出价低、预算不足、关键词覆盖少 | 提价、加预算、拓展相似词 |
| ACOS 健康且订单稳定 | 关键词或定向质量较高 | 保留、适度加预算、复制到手动广告 |
| 高花费高 ACOS | 流量过宽或竞争过强 | 细分广告组、降价、否定低效词 |

#### 第 4 阶段：AI 分析流程

目标：让 AI 基于飞书表格中的广告数据输出可复核建议。

1. 运营导出 AMS 广告报表。
2. 通过 `lark-cli` 上传或写入飞书表格。
3. AI 读取字段，按广告活动、关键词、搜索词三个层级做诊断。
4. AI 输出建议动作：保留、加预算、降价、加否定词、暂停、继续观察。
5. 人工复核建议，记录采纳情况。
6. 一周后回看效果，优化判断规则。

#### 第 5 阶段：AMC 与 API

目标：在 AMS 报表分析跑通后，再研究 AMC 和广告 API。AMC 适合做用户行为路径、复购、触点归因和更复杂的人群分析，但短期不应成为主线阻塞点。

- 先看懂 AMC 的核心概念：事件、受众、路径、归因、查询模板。
- 评估账号是否具备 AMC 使用权限。
- 了解广告 API 的申请条件，区分公共开发者与私有开发者路径。
- 后续再考虑把 API 接入到自动化分析流程。

### 两周执行计划

| 时间 | 任务 | 验收标准 |
|---|---|---|
| 第 1-2 天 | 确认试点产品，优先 Y10，其次 Y11 | 拿到产品 ASIN、广告投放状态、负责人 |
| 第 3-4 天 | 导出第一批 AMS 报表 | 至少包含广告活动、搜索词、关键词报表 |
| 第 5-6 天 | 建立飞书广告分析表结构 | 字段能支撑 ACOS、CTR、CVR、花费、订单分析 |
| 第 7-9 天 | 人工 + AI 做第一轮诊断 | 输出暂停、否定词、加预算、观察清单 |
| 第 10-12 天 | 和运营复核建议 | 明确哪些建议可执行，哪些需要补数据 |
| 第 13-14 天 | 形成第一版广告诊断 SOP | 沉淀为可复用模板和周报格式 |

### 近期任务清单

- [ ] 找运营部主管确认 Y10/Y11 试点产品，优先 Y10。
- [ ] 获取 AMS 账号权限，或先让运营导出广告数据。
- [ ] 确认第一批需要导出的报表：广告活动、搜索词、关键词、商品投放、已购商品。
- [ ] 建立飞书广告分析表字段结构。
- [ ] 整理第一版广告评价规则：保留、加预算、降价、加否定词、暂停、观察。
- [ ] 完成第一轮 Y10/Y11 广告数据诊断并和运营复核。
- [ ] 把有效规则沉淀成 SOP，并准备后续接入 `lark-cli` 自动化。

### 后续与视频素材的连接

广告优化不能只看投放动作，也要回到素材本身。后续视频素材研究可以和广告数据打通：每个视频素材需要记录创意方向、脚本类型、开头钩子、核心场景、产品卖点、投放数据。这样才能判断哪些创意真正带来更好的 CTR、CVR 和 ACOS。

> [!info] 第一阶段成功标志
> 拿到一批真实 AMS 数据后，能用 AI 给出一份运营看得懂、能复核、能执行的广告优化清单，而不是只解释指标。
