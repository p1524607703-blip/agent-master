# 亚马逊广告数据分析与运营-v2插件

> [!summary] 摘要
> 负责人现用的“亚马逊广告数据分析与运营-v2”是 25 工具完整权限应用，包含 10 个只读、14 个受控写入和 1 个数据库管理员工具。该生产应用及其 `amazon-ads-local` 隧道必须保持不动。开发部通过独立私有 GitHub Marketplace 绑定并共用这一现有管理员应用；运营团队另用完全独立的 10 工具只读副本。

## 核心知识

### 1. 生产插件现状

| 类型 | 数量 |
|---|---:|
| 只读查询工具 | 10 |
| 受控写入工具 | 14 |
| 数据库管理员工具 | 1 |
| 合计 | 25 |

生产插件用于负责人完成分析、报表导入、运营记录、复查和必要的数据库管理。它不是运营员工的分发版本，不得为了“统一权限”而改成只读。

### 2. 不可修改边界

- 不修改现有 `amazon-ads-local` Tunnel 的 MCP 命令、应用绑定或权限。
- 不把现有 OpenAI 应用 ID 放进运营 GitHub 插件包。
- 不在现有应用上测试工具删减、缓存刷新或只读模式。
- 每次运营版上线前后都要复查生产插件仍为 `25 = 10 + 14 + 1`。

### 3. 运营只读副本

运营版采用独立的五层隔离：

1. 独立 Python MCP 入口，只注册 10 个查询工具；
2. 独立 RDS 登录角色，只授予必要 `SELECT`，强制只读事务；
3. 独立 Secure MCP Tunnel；
4. 独立 OpenAI 应用；
5. 独立公开 GitHub Codex 插件包；公开仓库仅负责安装分发，不承担数据访问控制。

运营版禁止报表导入、任何新增/更新/删除、任意 SQL、DDL、数据库角色或权限管理。它只能读取广告表现、成熟归因、TIB、产品分类、入库健康和待复查清单。

### 4. 开发部管理员分发

- 私有仓库：`p1524607703-blip/amazon-ads-admin-codex-marketplace`。
- 插件：`amazon-ads-admin-full-access@amazon-ads-admin-team`。
- 绑定负责人正在使用的同一个 25 工具 OpenAI 应用，不复制、不修改生产 Tunnel、MCP 或 RDS 权限。
- 应用专属权限设为“允许所有操作”，但每位开发人员必须使用自己的公司 OpenAI 账号；禁止多人共用 ChatGPT 登录账号。
- GitHub 仓库只授予获准开发人员读取权限；仓库不得公开，也不得包含 RDS、Tunnel、密钥、生产数据或日志。
- 安装后必须在新任务中验证 `25 = 10 + 14 + 1`；若出现运营只读版的 10 工具目录，立即停止。

### 5. 验收规则

- 生产插件：总工具 25、只读 10、受控写入 14、管理员 1。
- 运营插件：总工具 10、只读 10、写入 0、管理员 0。
- 任一数量不符即停止发布；不得通过调整生产插件修复运营版。
- 新工具目录应在新任务中验证，避免旧会话缓存造成误判。

### 6. 数据安全

- 员工不接触 RDS 地址、账号密码、证书、Tunnel ID 或 API key。
- GitHub 公开仓库仅保存插件声明、只读 Skill 和安装说明，不保存任何密钥、数据或旧生产应用关联。
- GitHub 私有管理员仓库只保存管理员插件声明、应用关联、Skill 和安装说明，不保存 RDS 凭据或数据。
- 运营查询不可写回 `core`、`analytics`、`ops` 或 `chatgpt_ops`。
