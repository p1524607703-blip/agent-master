# 亚马逊自然单增长与广告依赖诊断

> [!summary] 摘要
> 自然单长期不上升，通常不是“广告开得太多”这一个原因，而是广告订单没有沉淀为目标搜索词的自然曝光、点击和购买。诊断应以总销量、TACOS、Search Query Performance 漏斗及关键词自然可见性为主，先修复商品竞争力与流量精准度，再集中验证少量高潜力词，最后小步降低广告依赖。

## 核心知识

### 先判断是不是真正的广告依赖

广告订单占比高只能描述归因结果，不能单独证明经营不健康。需要同时判断：

- 总销量是否增长；
- TACOS（广告花费 ÷ 总销售额）是否连续下降；
- 目标搜索词的 ASIN 展示、点击、加购、购买份额是否提升；
- 核心词自然可见性是否改善；
- 降低广告后总单量是否立即显著下滑。

若 ACOS 尚可，但 TACOS、总销量和自然购买份额长期不改善，广告更像是在持续购买订单，而非建立可持续增长。

### 常见根因

| 根因 | 典型信号 | 优先动作 |
|---|---|---|
| 搜索相关性或收录不足 | 核心词无稳定自然曝光；广告搜索词与 Listing 表达不一致 | 核对类目节点、标题、五点、属性、后台搜索词及广告成交词 |
| 广告流量过散 | 自动/广泛出单很多，但订单分散在大量词上 | 从搜索词报告收割高转化词，单独建立精准层；无效词否定或降价 |
| 搜索结果点击竞争力弱 | 展示有、CTR 低 | 对比前台同屏竞品的主图、价格、Coupon、评分、Review、配送承诺 |
| 商品页承接弱 | CTR 尚可、CVR 低；广告放量后 ACOS 快速恶化 | 修主图序列、五点、A+、视频、尺码/变体、评价痛点和价格结构 |
| 目标词难度超出资源 | 大词 CPC 高、转化差、自然位不动 | 暂停硬推大词，先打高相关腰部词和长尾词，积累销量与评价优势 |
| 运营稳定性问题 | 断货、丢 Buy Box、价格频繁变化、评分下降后自然单下滑 | 先恢复库存、价格、Buy Box 和评价健康，再测试广告 |
| 归因造成“广告占比虚高” | 自然位与广告位同时靠前，广告订单多但总量和 TACOS 健康 | 不为追求比例盲目停广告，以增量与利润判断是否减投 |

### 最小数据包

使用最近 28 天与前 28 天对比，至少准备：

1. Business Report：Sessions、Unit Session Percentage、总订单、总销售额。
2. Sponsored Products：Campaign、Search Term、Targeting、Placement、Advertised Product 报告。
3. Brand Analytics：Search Query Performance 的 ASIN 级查询词展示、点击、加购、购买及份额。
4. 前台状态：价格、Coupon、评分、Review 数、Buy Box、库存和主要变体。
5. 10–20 个核心搜索词的自然可见性趋势；看趋势，不迷信单次截图的绝对名次。

> [!warning] 指标口径
> `TACOS = 广告花费 ÷ 总销售额`。盈亏平衡 ACOS 应使用广告前贡献利润率计算，不直接套用行业固定值。广告销售占比与广告订单占比也不能混为一个口径。

### 关键词动作矩阵

| 广告表现 | 自然表现 | 动作 |
|---|---|---|
| CTR/CVR 高，订单稳定 | 自然可见性低但在改善 | 选入 3–5 个优先词，集中精准预算并持续观察自然漏斗 |
| CTR 高、CVR 低 | 自然位弱 | 先修 Listing、价格、评价和变体，不靠提高竞价硬推 |
| 高花费、低相关、无转化 | 无自然改善 | 降价、否定或暂停 |
| 自动/广泛发现稳定出单词 | 尚未进入精准层 | 收割到手动精准，发现层做相应隔离，避免内部抢量 |
| 自然购买份额已经较高 | 广告增量有限 | 进入小步减投测试，不一次性关闭 |

### 14 天执行方案

#### 第 1–2 天：建立基线

- 计算 ACOS、TACOS、广告订单占比、总销量、Sessions 和 CVR 的双周期变化。
- 从 Search Query Performance 与广告搜索词中选出 3–5 个“高相关、有转化、当前自然份额仍低”的词。
- 分开判断 TOS、ROS、商品页面的 CTR、CVR、CPA；不默认 TOS 一定最好。

#### 第 3–5 天：修复承接

- 在目标词搜索结果页逐项对比主图、价格、Coupon、评分、Review 和卖点差异。
- 让标题、五点、属性、后台搜索词、图片和 A+ 清晰表达目标词对应的功能、场景与人群，而不是机械堆词。
- 处理断货风险、Buy Box、差评集中点、尺码/变体选择成本。

#### 第 6–12 天：集中验证

- 每个目标只承担一个明确目的：推词、盈利、拓词或防守，避免混在同一活动中难以判断。
- 将验证过的 1–3 个目标词放入独立的 SP 手动精准层，给予可持续预算；自动/广泛层继续发现，但剔除已收割词和低相关浪费词。
- 每日看异常，每 7 天做一次正式决策；观察总销量、TACOS、目标词漏斗和自然可见性是否同步改善。

#### 第 13–14 天：判断是否减投

- 只有当总单量稳定、TACOS 下降、目标词自然购买份额或可见性持续改善时，才进行减投测试。
- 每轮只下调目标词竞价或预算 10%–20%，保持 7–14 天观察窗口；若总单量和自然可见性同步下滑，则恢复并重新诊断。
- 将预算转移到下一批高潜力词，而不是简单追求“自然单占比好看”。

### 如何判断方案有效

- **真增长**：总销量稳定或上升，TACOS 下降，目标词自然漏斗份额和自然可见性提升。
- **广告买单**：ACOS 好看，但总销量不增、TACOS不降、自然表现不变。
- **页面瓶颈**：加曝光后 CTR/CVR 仍弱，竞价越高亏损越快。
- **选词错误**：目标词搜索需求大，但商品相对竞品没有价格、评价、功能或场景优势。

> [!warning] 证据边界
> 知乎帖子普遍认为“关键词下的广告成交可帮助自然位”，但亚马逊没有公开自然排序权重，也没有官方确认某一广告类型或广告位必然提升自然排名。执行时应把这类观点当作待验证假设，以 Search Query Performance、总销量和 TACOS 结果决定去留。刷单、刷广告单、操纵评论等违规方法不纳入方案。
