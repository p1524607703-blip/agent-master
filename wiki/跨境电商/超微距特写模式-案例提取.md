# 手机端超微距特写模式 — 案例提取与 V4 适配

## 一、案例原文

```
越野跑鞋大底的超微距特写摄影，展示了复杂的几何形状防滑齿图案。
橡胶材质呈现出荧光石灰绿与炭灰色的混合大理石纹理。
细节上带有轻微的灰尘和泥土颗粒。
背景是阳光明媚的森林，极度柔和的焦外散景。
戏剧性的自然侧光增强了纹理和立体感。
前景锐利对焦，极浅景深。
高清写实，8k。
```

## 二、共性提取：7 层结构

| # | 层 | 案例关键词 | 通用化表达 | 鞋类适配 |
|---|---|---|---|---|
| 1 | **拍摄方式** | 超微距特写摄影 | 超微距特写 / 极近景 | 不限于大底，可适配任何鞋类局部（鞋面、鞋头、后跟、魔术贴） |
| 2 | **被摄主体** | 复杂的几何形状防滑齿图案 | 聚焦该变体最核心的材质或工艺细节 | 鞋面编织/网布、外底齿纹、鞋头宽楦空间、后跟软垫、魔术贴结构 |
| 3 | **材质纹理** | 荧光石灰绿与炭灰色的混合大理石纹理 | 材质纹理放大呈现其复杂图案（编织/压花/几何纹路等） | 网布编织纹理、橡胶防滑纹、皮革压花、飞织针织纹路 |
| 4 | **真实感细节** | 轻微的灰尘和泥土颗粒 | 保留轻微使用痕迹（灰尘/泥土颗粒/纤维毛边） | 新鞋也可用「刚拆封的纸屑纤维」替代使用痕迹 |
| 5 | **背景** | 阳光明媚的森林，极度柔和的焦外散景 | 场景化环境 + 极度柔和的焦外散景虚化 | 根据品类匹配：户外→森林草地，通勤→街景，儿童→操场 |
| 6 | **光影** | 戏剧性的自然侧光增强了纹理和立体感 | 自然侧光增强凹凸立体感 | 所有鞋类通用 |
| 7 | **景深与画质** | 前景锐利对焦，极浅景深。高清写实，8k | 极浅景深，高清写实 | 所有鞋类通用 |

## 三、应用：V4 模块三/四手机端

### 模块三手机端（新）

```
【手机端 — 超微距特写模式】
· 聚焦该变体最核心的材质或工艺细节（鞋面纹理/外底齿纹/鞋头空间/后跟结构/魔术贴），做超微距特写
· 材质纹理放大呈现其复杂图案（编织/压花/几何纹路等），辅以自然侧光增强凹凸立体感
· 细节上保留轻微使用痕迹（灰尘/泥土颗粒/纤维毛边），增强真实感
· 背景为场景化环境（户外草地/步道/操场等），极度柔和的焦外散景虚化，前景锐利对焦
· 极浅景深，高清写实
· 不加入放大圈和引导线
· 文字（标题+副标题）位于留白区
```

### 模块四手机端（新）

```
【手机端 — 超微距特写模式】
· 聚焦该变体与变体 1 不同的材质或工艺细节，避免同一部位重复
· 材质纹理放大呈现其复杂图案，辅以自然侧光增强凹凸立体感
· 细节上保留轻微使用痕迹，增强真实感
· 背景场景须与模块三手机端差异化，极度柔和的焦外散景虚化，前景锐利对焦
· 极浅景深，高清写实
· 不加入放大圈和引导线
· 文字位于留白区
```

## 四、旧版 vs 新版对比

| 维度 | 旧版 | 新版 |
|---|---|---|
| 拍摄方式 | 「产品穿搭场景 + 近景特写」 | 「超微距特写摄影」 |
| 产品占比 | 「鞋子占画面 80%」 | 不指定百分比，强调「材质纹理放大」 |
| 背景处理 | 「远景模糊虚化」 | 「场景化环境 + 极度柔和的焦外散景虚化」 |
| 光影 | 未提及 | 「戏剧性自然侧光增强纹理和立体感」 |
| 景深 | 未提及 | 「极浅景深，前景锐利对焦」 |
| 真实感 | 未提及 | 「使用痕迹（灰尘/泥土/纤维毛边）」 |
| 画质 | 未提及 | 「高清写实」 |
| 禁止元素 | 「不加入放大圈和引导线」 | 保留 |
