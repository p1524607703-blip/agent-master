# 亚马逊DSP与AMC-代理商方案与分析框架

> [!summary] 摘要
> 2026-08 上旬梳理的 Amazon DSP 代理商投放方案（按产品角色配受众策略）与运营侧自建的 DSP+AMC 分析框架（All/P+ 四路径拆分、消费者旅程视角、优化闭环），以及 DSP 实验设计模板和当前待确认事项。

## 核心知识

### 1. 代理商投放方案

代理商不直接搭建复杂四层漏斗，而是**先按产品角色分类**：

| 产品类型 | 配置策略 |
|---|---|
| 大众低价款 | 宽泛策略引流，重流量成本与量 |
| 品牌引流款 | 品牌触达 + 承接 |
| 精准需求款 | In-Market / 竞品等定向策略 |

策略池：All Audiences、Performance+（Customer Acquisition P+）、In-Market、竞品等。**第一阶段先用成熟组合建立账户基准线（CPM、DPVR、CPA、ROAS、NTB）**，数据成熟后再逐步引入 P+ OLV、AMC Audience、竞品与其他扩展策略。

策略角色定位：

- **All Audiences = 宽泛探索**；
- **Customer Acquisition P+ = 算法型高概率新客捕获**；
- **IM / Lifestyle / CMP / AMC Audience = 人工指定方向与精细化验证**。

> [!warning] 考核口径
> 不能把所有 DSP 广告按 ROAS 横向排名。低价引流款同时看新客、DPV、eCPDPV 和流量成本；上层视频结合触达、加购和后续品牌搜索判断。

### 2. DSP + AMC 分析框架（运营侧自建）

核心思路从"哪个 Campaign ROAS 更高"转向"每个 Campaign 在消费者旅程中承担什么作用"。

**AMC 四路径拆分**：All Only / P+ Only / All → P+ / P+ → All。观察指标：用户覆盖、DPV、ATC、Purchase、NTB、CPA、ROAS、后续站内广告路径。

要回答的问题：All 是否发现了 P+ 没覆盖的新用户？P+ 是否独立捕获高价值新客？策略间是重复触达还是有效接力？组合整体是**扩大开口**还是**内部空转**？

**优化闭环**：单策略效率 → 策略重叠 → 用户触达顺序 → Broad 人群特征发现 → IM/Lifestyle 等人工验证 → AMC 高价值 Audience 沉淀 → P+/Remarketing 承接 → AMC 再验证最终增量。

**DSP 定位**：不只作为再营销工具，需与 SP、SD、SBV 等站内承接共同观察；AMC 的价值不是多一张报表，而是回答"不同受众/路径在哪个环节带来增量，新客和转化是否真正来自 DSP 而非站内广告归因迁移"。

### 3. DSP 实验设计模板（会议要求）

每个测试至少提前写清：**业务目标 → 产品 → 用户 → 受众 → 广告 → 承接 → 预算 → 验证指标**，而不是"有这个功能所以试一下"。内部试投必须提前写清目标、受众、预算边界和验证方法。
