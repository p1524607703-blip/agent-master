# 亚马逊自然单增长方法综述-2023至2026

> [!summary] 摘要
> 本文汇总 2023 年至 2026 年 99 篇知乎相关帖子，并深读其中 38 篇核心资料。高频且较可信的共识不是“把广告停掉”，而是先修复商品竞争力、关键词相关性和搜索漏斗，再用自动/广泛发现有效搜索词、以手动精准承接，并按总销量、TACOS、查询词份额和利润逐步减投。广告订单占比只是结果指标；亚马逊没有公开证明某种广告类型、广告位或固定订单量必然提升自然排名。

#### 如何计算“出现频率”

1. 先把帖子中的做法编码为 25 类方法。
2. 同一篇帖子对同一方法无论重复多少次，只计 1 次。
3. 主排序采用“提到该方法的不同作者数”，辅以“提到该方法的文档数”，避免同一作者多篇相似文章把频率虚高。
4. 计频是文本编码，不是效果实验；有些帖子会同时提到某方法及其反例，因此频率代表“被讨论程度”，不等于成功率。

#### 合理程度分级

| 分值 | 含义 |
|---|---|
| 5.0 | 可直接观测、可做对照实验，且与 Amazon 官方功能说明一致 |
| 4.0–4.5 | 机制合理、可验证，但不存在公开的自然排名因果承诺 |
| 3.0–3.5 | 强依赖类目、生命周期、样本量或执行条件 |
| 1.0–2.5 | 经验性强、使用了无法核验的固定权重/固定阈值，或把相关性说成因果 |
| 0 | 违规、高风险或不应采用 |

> [!warning] 证据边界
> 知乎资料是卖家经验，不是 Amazon 官方排名说明。Amazon 官方明确提供自动/手动/否定投放、搜索词报告、广告位调整和商品页优化建议，但没有公开“广告订单直接增加自然排名”的权重公式。本文把“广告推自然位”改写为待验证假设：广告可能带来相关搜索词下的展示、点击和购买数据，但自然表现是否改善，必须由查询词份额、自然可见性、总销量和利润共同验证。

### 二、先给结论：为什么自然单一直上不去

高广告占比本身不是病因，而是以下问题之一的表现：

1. **广告买到订单，却没有建立可持续的目标搜索词表现。** 订单分散在大量词、ASIN 和低相关流量中，核心词的自然展示、点击、加购、购买份额没有持续改善。
2. **商品页承接能力不足。** 主图、价格、Coupon、评分、Review、配送、变体或卖点落后于同屏竞品；广告放量只会放大低 CTR/低 CVR。
3. **目标词选错。** 一开始硬推高流量大词，但产品在功能、价格、评价和预算上没有相对优势；越加竞价，亏损越快。
4. **Listing 相关性与收录不完整。** 类目、标题、属性、五点、后台搜索词和广告成交词不一致，导致系统与消费者都难以判断产品适合什么需求。
5. **广告结构承担了过多职责。** 一个活动同时拓词、推词、盈利、防守，数据无法解释；或曝光/订单过度集中于单一活动，停投即断流。
6. **价格、库存、Buy Box、评分或主力变体不稳定。** 这些因素可直接影响可售状态和转化，广告无法替代。
7. **只看 ACOS 或广告单占比。** ACOS 可以变好而总销量不增长；广告占比也会因归因、自然位与广告位重叠而看起来偏高。应同时看 TACOS、利润、总单量和查询词漏斗。

所以，解决顺序应是：**查询词诊断 → 商品竞争力 → 流量精准度 → 广告结构 → 自然表现验证 → 渐进减投**，而不是先停广告。

### 四、最应优先采用的方法

#### 1. 先把“自然单问题”拆成查询词漏斗问题

不要只看 ASIN 总体广告单占比。对 10–20 个核心查询词分别观察：

- 搜索需求是否真实存在，是否有季节性；
- ASIN 的查询词展示份额、点击份额、加购份额、购买份额；
- 广告搜索词的曝光、点击、CTR、花费、CPC、订单、CVR、CPA；
- 自然可见性是持续改善、横盘还是下降；
- 同屏竞品的主图、价格、Coupon、评分、Review、配送和卖点。

Amazon 的 Search Query Performance 可按查询词查看展示、点击、加购和购买表现；广告搜索词报告可以发现高绩效搜索词及待否定词。两者结合，才能区分“需求不足”“点击不足”“页面转化不足”和“广告买单但自然未沉淀”。

#### 2. Listing 与商品竞争力决定流量能不能被承接

帖子中最高频的共识是：自然单不升时，先检查 Listing 和产品，而不是只调竞价。建议分两层判断：

**搜索结果页点击竞争力**

- 主图能否在移动端缩略图下快速说明产品是什么、适合谁；
- 价格、折扣、Coupon、配送时间是否落后于同屏竞品；
- 星级、Review 数、品牌识别度是否形成明显劣势；
- 标题前半段是否表达核心品类、关键差异和主要使用场景。

**详情页购买竞争力**

- 图片序列是否回答尺寸、材质、使用方法、兼容性、场景和常见顾虑；
- 五点、A+、视频、QA 与评论是否共同消除购买风险；
- 变体命名、尺码/颜色选择是否清晰，主力变体是否有货；
- 差评和退货原因是否指向产品本身，而不是文案表达问题。

若目标词曝光增长，但 CTR 低，优先修搜索结果页；CTR 尚可而 CVR 低，优先修详情页、价格、评价和产品匹配。两者都弱时，提高竞价只会更快暴露问题。

#### 3. 关键词按“相关性 × 意图 × 难度 × 经济性”分层

高频帖子普遍反对一开始只攻泛大词。可把关键词分为：

| 层级 | 特征 | 主要动作 |
|---|---|---|
| 核心高意图词 | 与产品强相关，已有点击和购买，竞争可承受 | 手动精准独立验证，持续观察查询词漏斗和自然趋势 |
| 腰部场景/功能词 | 搜索量较低，但需求描述具体、CVR 较好 | 作为预算有限时的优先突破口 |
| 长尾发现词 | 由自动/广泛产生，样本小但相关 | 保留发现层，达到样本门槛后转入手动层 |
| 泛大词 | 流量大、CPC 高、意图混杂 | 只有产品竞争力、预算和利润线支持时才扩大 |
| 低相关或无效词 | 点击多、无转化，或需求与产品不匹配 | 降价、否定或暂停 |

#### 4. 用“发现层→验证层→规模层”重建广告结构

Amazon 官方建议可以用自动投放发现搜索词，再以手动投放获得更精细的控制；搜索词报告用于识别高绩效词和低效词。更可解释的结构是：

1. **发现层**：自动、广泛或词组；目标是找词和找 ASIN，不以短期最低 ACOS 为唯一目标。
2. **验证层**：把已产生相关点击/订单的搜索词转入手动精准；每个活动/广告组承担明确目标。
3. **规模层**：对稳定达到 CPA/利润要求的词扩预算、位置或匹配范围。
4. **防守/截流层**：品牌词、自有 ASIN、竞品 ASIN、类目投放独立管理。
5. **隔离与否定**：对已转入精准层的词做适当流量隔离；对确认无效的词否定，避免发现层长期重复付费。

这套结构的价值是归因和决策清晰，不是“账户越复杂越好”。低销量 ASIN 可以用更少活动完成同样的目标分离。

#### 5. 广告位只按数据调整，不按口号抢 TOS

TOS、ROS、商品页面的竞争环境不同。正确做法是下载广告位报告，分别计算 CTR、CVR、CPC、CPA/ROAS，再决定基础竞价与位置加价。新品、低评价或价格劣势产品强抢 TOS，可能因同屏竞品更强而迅速拉高 ACOS。

#### 6. 用利润和 TACOS 判断广告是否在“支撑”还是“拖累”

至少同时看四个口径：

- `ACOS = 广告花费 ÷ 广告销售额`；
- `TACOS = 广告花费 ÷ 总销售额`；
- `CPA = 广告花费 ÷ 广告订单/购买数`；
- 广告前贡献利润率与盈亏平衡 CPA/ACOS。

如果 ACOS 可接受，但总销量不增长、TACOS 不下降、目标查询词购买份额不改善，广告更像在持续购买现有订单。若广告占比高，但总利润、总销量和目标词份额持续增长，则不应为了“比例好看”盲目停投。

### 五、其他方法的适用条件与限制

#### 评价、价格、库存、Buy Box 与变体

- **评价与信任**：应通过产品质量、合规售后、Vine 等允许方式积累。评论数量不是唯一目标，星级、内容是否回答顾虑、近期差评和退货原因更重要。
- **价格与促销**：适合做受控实验。一次只改一个主要变量，记录前后 CTR、CVR、总销量和利润；频繁大幅调价会使广告与自然表现难以解释。
- **库存与 Buy Box**：断货、低库存、配送变慢或丢失 Featured Offer 时，优先恢复可售基础。补货后“立刻把预算加满”只是个别卖家经验，仍应设置 CPA/花费止损。
- **变体**：相关且合规的变体可降低选择成本并共享页面资产；不相关合并会造成政策风险和错误转化信号。

#### ASIN、类目、站外与品牌流量

- **商品/类目投放**：当产品在价格、评价、功能或套装上相对目标 ASIN 有优势时更合理；否则容易产生比价点击而不成交。
- **站外流量**：适合有明确受众、可追踪链接和高承接力页面的产品。站外访问量本身不等于高质量购买信号，弱转化流量可能稀释整体表现。
- **品牌内容**：旗舰店、品牌视频、A+ 品牌故事、社媒内容和品牌搜索有长期价值，但不能用短期自然单目标评价所有品牌投入。

#### 新品窗口、分时投放与预算集中

- 新品期应更快完成收录检查、获取有效点击和首批购买样本，但不存在所有类目统一的“7 天/14 天/30 天权重窗口”。
- 分时投放必须建立在小时级成熟数据上；应看同星期、同广告类型和相近竞价条件，不套用他人“早上好/晚上好”的时段表。
- 预算有限时集中 3–5 个高潜查询词，比同时推几十个词更容易形成稳定样本；但应保留一定发现预算，避免锁死在错误词上。

#### 销量速度、BSR、SPR 与“反弹率”

- BSR 是相对排名结果，可辅助观察销量变化，但不是关键词自然排名的直接替代指标。
- SPR、所谓“8 天上首页所需订单数”等通常来自第三方估计，能做资源粗算，不能当作 Amazon 给出的任务量。
- “反弹率”“养排名”等概念可被重新解释为：减小广告后，总销量和自然可见性是否能保持。如果定义不清、无法从报表复现，就不应作为核心 KPI。

### 六、原帖中需要降级或排除的观点

| 观点 | 判断 | 处理方式 |
|---|---|---|
| “广告订单会直接增加自然权重” | 相关性可能存在，但 Amazon 未公开直接因果或权重 | 只作为实验假设，用查询词自然份额和总量验证 |
| “SP 手动精准最能推自然位，SB/SD 对自然位为 0” | 精准投放控制力强；广告类型对自然排序的固定贡献没有官方依据 | 采用其结构控制价值，删除绝对权重结论 |
| “TOS 订单对排名贡献一定高于 ROS/PP” | TOS 常有更高可见性，但转化、成本和竞品强度因类目而异 | 只按位置报告决策 |
| “TOS CTR 约 6%、ROS 1%、PP 0.5%” | 属于作者样本，不能外推 | 不设为基准，用本账户同位置历史值 |
| “新品广告单应占 60%–80%，成熟期应降到 10%–20%” | 生命周期方向有参考性，比例不具普适性 | 用利润、TACOS、总量和增量替代固定比例 |
| “自然单应达到 70% 以上” | 会因类目、品牌、客单价、生命周期和归因而变化 | 不设统一目标 |
| “达到某个 SPR 订单数即可上首页” | 第三方估计且无法控制竞品变化 | 仅用于压力测试，不作承诺 |
| “重开广告可以重置权重、救活广告” | 缺少官方依据；重新建活动会丢失连续对照 | 优先修正目标、出价、否定与承接，除非结构本身错误 |
| “A9/A10/COSMO/Rufus 有明确固定权重” | 帖子常混用算法名，缺少可核验公式 | 保留“理解意图、语义清晰”的方向，删除权重数字 |
| 刷单、刷广告单、刷评、无关变体合并 | 违规且会造成账号与数据风险 | 完全排除 |

### 七、可直接执行的 42 天方案

#### 第 0–3 天：建立双周期基线

准备最近 28 天与前 28 天：

1. Business Report：Sessions、总订单、总销售额、Unit Session Percentage。
2. Sponsored Products：Campaign、Targeting、Search Term、Placement、Advertised Product。
3. Search Query Performance：核心查询词的展示、点击、加购、购买及 ASIN 份额。
4. 前台与商品数据：主图、标题、价格、Coupon、评分、Review、库存、Buy Box、主要变体。
5. 10–20 个核心词的自然可见性趋势；如果使用第三方排名工具，只看趋势和页面区间。

把自然单问题分为四类：需求下降、点击不足、转化不足、流量结构/可售状态异常。

*原帖用核心词贡献和排名趋势定位风险。不要把第三方“健康度/缺口”标签当作平台字段。来源同上。*

#### 第 4–10 天：先修承接，不急着扩广告

- 对目标查询词做同屏竞品审查，修复主图、价格、Coupon、标题前段、核心卖点和配送差距。
- 检查类目、属性、标题、五点、后台搜索词、图片文字和 A+ 是否围绕同一真实需求表达。
- 处理库存、Buy Box、评分下降、差评集中问题和主力变体异常。
- 一次只改一组主要变量，保留修改日期，避免无法判断效果。

#### 第 11–24 天：重构广告并验证 3–5 个高潜词

- 发现层保留自动/广泛/词组，用于发现搜索词与 ASIN。
- 把高相关、有购买或稳定转化的搜索词转入手动精准验证层。
- 每个活动明确属于拓词、推词、盈利或防守之一。
- 对确定无关或累计样本充分仍无转化的搜索词降价、否定或暂停。
- 分位置看 TOS/ROS/PP，只有某位置在 CPA/CVR 上具备优势时才加价。
- 每日看预算耗尽、异常 CPC 和断货；每 7 天做一次正式优化，避免按单日波动频繁改动。

![[attachments/亚马逊自然单增长方法综述-2023至2026/09-广告结构诊断示例.jpg]]

*原帖用活动数量、曝光集中度、投放节奏和结构复杂度诊断单一活动依赖。来源同上。*

#### 第 25–35 天：判断有没有形成自然增量

每个目标词至少回答：

- 广告订单增加时，总订单是否同步增加；
- 查询词购买份额是否上升；
- 自然可见性是否连续改善，而不是单日跳动；
- TACOS 是否下降或至少没有恶化；
- 增量毛利是否覆盖广告与促销成本。

若只有广告销售增加，查询词份额、自然趋势和总量都没改善，应停止“推位”叙事，回到选词、产品竞争力和 Listing 承接。

![[attachments/亚马逊自然单增长方法综述-2023至2026/06-关键词自然位与广告位趋势.jpg]]

*原帖把自然位、SP/SB/SBV 广告位和关键词趋势并列观察。来源：[为什么 TOS 加到 900% 还是没曝光](https://zhuanlan.zhihu.com/p/2066171537049249005)。第三方自然位受时间、地点、个性化和页面变化影响，只宜看趋势。*

#### 第 36–42 天：小步减投与预算再分配

只有满足以下条件才减投：总单量稳定、目标词查询份额或自然可见性改善、TACOS/利润可接受、库存安全。

- 每轮只改变一个主要变量，例如竞价或预算下调 10%–20%；该比例是保守起点，不是固定规则。
- 观察至少一个完整购买周期；低销量或长决策类目需要更长窗口。
- 若自然与总量同步下滑，恢复设置并重新判断广告是否仍有增量价值。
- 若总量稳定且利润改善，把释放预算转向下一批高潜词，而不是单纯追求低广告占比。

### 八、成功、失败与停止条件

| 结果 | 证据组合 | 下一步 |
|---|---|---|
| 真正形成自然增长 | 总销量稳定/上升；TACOS下降；目标词购买份额和自然趋势改善 | 逐步减投并扩展下一批词 |
| 广告只是在买单 | 广告销售增加，但总销量、查询词份额和自然趋势不变 | 收缩无增量目标，重做选词/Listing |
| Listing 承接失败 | 展示增加，CTR/CVR仍弱；提高竞价后CPA恶化 | 停止硬推，优化商品页和商品竞争力 |
| 目标词选错 | 泛词花费高、CVR低，腰部/长尾反而稳定 | 将预算迁移到高相关具体需求词 |
| 结构过度集中 | 单一活动停投即流量断崖，曝光/订单集中度过高 | 分目标建立冗余和可解释结构 |
| 可售状态异常 | 断货、丢 Buy Box、配送变慢、主力变体异常 | 先恢复商品状态，再评价广告 |
