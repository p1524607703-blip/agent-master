# 亚马逊品牌分析与搜索热度驱动的开品报告方法

> [!summary] 摘要
> 开品报告可以沿用18字段意图分类，但必须增加需求规模、趋势稳定性、购买深度、竞争结构和产品可行性。18字段回答“用户为什么搜索”，品牌分析和选品工具回答“该意图有多大、是否增长、由哪些商品承接”，成本与合规数据决定“是否值得开发”。

## 核心知识

### 分析层级

1. 语义意图层：对搜索词提取产品、人群、功能、场景、身体需求、替代品和潜在任务。
2. 需求规模层：使用查询量、搜索热度、搜索频率排名、趋势和季节性对意图簇加权。
3. 购买深度层：观察搜索漏斗中的点击、加购和购买表现，区分流量词与交易词。
4. 竞争结构层：分析头部 ASIN 的点击/购买集中度、价格带、评分评论门槛和商品同质化。
5. 产品可行性层：结合成本、毛利、尺寸重量、退货风险、合规和供应链难度形成开发判断。

### 推荐指标

- `intent_demand_share`：意图簇加权搜索热度 / 全部相关意图热度。
- `growth_index`：近期搜索热度相对历史基线的变化。
- `seasonality_index`：旺淡季波动程度。
- `purchase_depth`：购买量或购买率相对点击、加购的漏斗深度。
- `click_concentration` 与 `purchase_concentration`：头部 ASIN 对流量和购买的控制程度。
- `competitive_gap`：高需求、低承接或低集中市场中的机会强度。
- `product_feasibility`：商品规格、成本、毛利、物流、退货和合规的综合可行性。
- `evidence_confidence`：数据源、日期、样本范围和估算方法的可靠程度。

### 关键规则

- 先对同义词、拼写变体和长尾组合去重归簇，再汇总搜索热度，避免重复计算需求。
- 品牌词、竞品词与无品牌需求分别统计，不能把竞品导航流量直接当作可争夺需求。
- 第三方搜索量用于相对排序，优先用亚马逊品牌分析数据校准，不把估算值当成官方绝对市场规模。
- Search Query Performance 更适合分析自有品牌或 ASIN 已经触达的查询，不代表完整市场全貌。
- 一个意图簇应分别输出需求、增长、购买深度、竞争缺口和产品可行性，不建议只给一个缺少解释的总分。
- 最终开品决策应为 `go`、`conditional_go`、`test_first`、`hold` 或 `no_go`，并列出触发条件和最小验证实验。

### 标准流程

```text
搜索词汇总与标准化
→ 18字段意图标注
→ 同义任务归簇
→ 搜索热度与趋势加权
→ 点击/加购/购买漏斗验证
→ 头部ASIN与价格带竞争分析
→ 未满足需求识别
→ 产品规格、成本与合规评估
→ 开品结论与最小验证方案
```
