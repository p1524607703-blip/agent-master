# 亚马逊广告插件隔离规则

- 现有「亚马逊广告数据分析与运营-v2」是用户本人正在使用的 25 工具插件，包含 10 个只读、14 个受控写入和 1 个管理员工具；不得为了运营测试把它或其现有 Tunnel 改成只读。
- 运营版必须复制为完全独立的一套：独立 MCP 启动入口、独立 Tunnel、独立注册应用、独立 Codex 插件和独立 RDS 只读账号。
- 运营版只能读取，不注册导入、增删改、任意 SQL、DDL 或权限管理工具。
- 测试期间不得让运营插件 `.app.json` 指向现有 25 权限应用 ID。
- 任何工具目录变更都要在独立测试应用中验证，不能用生产网页端应用做实验。
- 运营和开发人员都使用各自的个人版 ChatGPT/Codex 账号，不以 Business 或“公司工作区”为前提。
- GitHub 备份只能复制插件文件，不能复制某个个人账号的应用连接和授权；新个人账号必须由无绑定安装器创建账号专属应用映射。
- Secure MCP Tunnel 必须关联目标个人 Platform 组织和 ChatGPT 个人空间；若要求任意个人账号无需管理员预关联即可开箱使用，应部署带 OAuth 的公共 HTTPS MCP。
