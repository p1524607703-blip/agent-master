# V4 提示词三项改进 — 预览版

> 审阅通过后一次性写入 V4 飞书文档。

---

## 改进一：运营提问颗粒度改造

> 替换位置：V4 第一步「提问收集 3 个关键运营问题」— 全部替换
> 改动原因：当前三个开放式问题颗粒度过粗，运营经常只填「男性 25-45 岁」这种无效答案；AI 应自主思考并提供结构化选项让运营快速选择

### 新内容

```
【第一步：提问收集运营关键信息】

⚠️ 以下每个问题，你必须先根据第零步抓取的产品信息（品类、定价、变体），
自主思考 3-5 个最匹配的预设选项供运营直接回复序号，再附一个开放式补充入口。
每题都可以说「跳过」，AI 按行业通用数据推断并在结论中标注「行业推断」。


问题 1 — 目标人群画像：

根据本产品的品类和定价，自主列出 3-5 个最可能的典型目标人群，
用序号 1/2/3 排列，每条一句话描述。末尾加上「以上都不是，请自由描述」。

格式示例（不要让运营看到这些具体案例——这是给你的格式示范，你用同类格式但填入你自己的推理内容）：
「根据你的产品属于[XX品类]，我推测最可能的目标人群是：
1. [一条描述]
2. [一条描述]
3. [一条描述]
以上都不是？请自由描述。」

如果用户跳过 → 我按品类和定价反向推断。


问题 2 — 品牌定位与差异化方向：

根据本产品的品类和定价区间，自主列出 3-5 个可能的品牌定位与竞品对标方向，
用序号 1/2/3 排列，每条一句话。末尾加上「以上都不是，请自由描述」。

如果用户跳过 → 我按品类主流竞品推断。


问题 3 — 差评与退货数据：

提供两条路径供用户选择：

1. 直接从后台导出原始差评/退货原因数据，粘贴给我（最精准）
2. 凭记忆列出你最常看到的 3-5 个差评关键词（快速版）

两者都无法提供 → 说「跳过」，我按该类鞋品行业通病推断。

收到你的回答后，我将立即进入推理阶段。
```

## 改进二：AI 自主思考品类红线

> 插入位置：V4 第二步推理链「推理结论 1」之前，作为前置知识注入
> 改动原因：合规专员评审发现赤足/zero-drop/wide toe box 品类 3 大红线未被覆盖，Module 2 对比图天然倾向 Before/After

### 新内容

```
———— 前置步骤二：品类红线自检 ————

⚠️ 在推理核心痛点之前，你必须根据第零步抓取的「品类」信息，
自主识别该类鞋品在 Amazon A+ 中最容易触犯的合规红线，并在后续推理和文案中
自觉规避。三条核心原则：

1. 禁止将产品设计参数（如零落差、宽鞋头）关联身体功能改善声明
2. 英文文案禁止 best/guaranteed/pain relief/eco-friendly(无证据时)/折扣信息
3. 模块二的对比画面始终比较产品与数据，不得出现人体 Before/After 对比

其他品类红线由你根据专业知识自主判断和规避。
```

## 改进三：AI 向用户新增两个提问

> 插入位置：
> - 提问一：V4 模块一 Hero 3 场景输出后，替换「场景选择引导」段落
> - 提问二：V4 第五步提示词重构中，7 层规则之前插入

### 提问一：Hero 场景选择引导矩阵

```
【场景选择引导】

输出 3 个 Hero 场景方案后，你必须基于第一步已确认的目标人群和品牌定位，
自主生成一个场景选择引导矩阵，帮助运营快速决策。

矩阵格式（用序号而非固定文案，AI 自行填入推理内容）：
「根据你的目标人群和品牌定位，我的推荐如下：
· 如果你的核心人群是[从第一步提取]，推荐选场景[X] — 理由是[一句话]
· 如果你更侧重[另一方向]，推荐选场景[Y] — 理由是[一句话]
· 如果追求[第三方向]，推荐选场景[Z] — 理由是[一句话]
你也可以直接回复 A/B/C，或者说'换一个XX方向'让我调整。」

严禁使用「赤足跑者→A」「初学者→C」等死映射——每次根据实际 3 个场景的内容和
第一步确认的人群，重新推理推荐关系。
```

### 提问二：超微距 7 层细节对比梯度

```
———— 细节对比梯度选择 ————

⚠️ 在进行 7 层重构之前，请先询问用户对「真实感细节」的偏好：

「在生图提示词中，鞋子表面细节的真实感程度你希望控制在哪个级别？
这会影响图片给人'全新品'还是'使用中'的视觉感受。」

请选择（回复 1 / 2 / 3）：

① 干净出厂级 — 鞋子表面无磨损痕迹，保留刚拆封的纸屑纤维或全新橡胶光泽。
   适合：品牌旗舰店风格、高端赤足鞋、生活方式品类
   提示词示例：细节上可见刚拆封的细微纸屑纤维和出厂橡胶的哑光光泽

② 轻度使用级（默认推荐）— 鞋底和鞋面带有轻微穿着痕迹，
   灰尘颗粒、操场塑胶微屑附着，但不显脏。整体仍保持「新鞋」的整洁感。
   适合：户外运动鞋、赤足鞋、跑步鞋，传递「真实穿着不摆拍」
   提示词示例：细微的灰尘颗粒和操场塑胶微屑附着在鞋底齿纹之间，鞋面有轻微穿着折痕

③ 重度使用级 — 明显的泥土斑点、鞋底磨损区域、网面起球或皮革折痕。
   适合：工装鞋、户外鞋、徒步鞋，强调「经得起折腾」
   提示词示例：鞋底前掌区域呈现明显的磨损抛光痕迹，鞋面散布干涸的泥土斑点，
            网面编织处有轻微起球和纤维拉丝

你希望选择哪个级别？（回复 1 / 2 / 3，不回复默认按 ② 轻度使用级处理）
```
