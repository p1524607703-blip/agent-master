## 1. 规范网页项目的开发流程与关键产出物

| 阶段 | 关键产出物 | 本项目现状 |
|------|-----------|-----------|

| **5. 编码** | 源码、组件文档、代码注释规范 | ⚠️ 代码在，规范无。无组件库、无 lint 记录 |

## 2. 文档补齐优先级（MoSCoW 排序）

排序依据：**阻断了什么** × **补写成本**。能解除阻塞、成本低的优先。

**① 工程基座（严格说不是文档，但是所有文档的前提）**

- 修正 `.gitignore`：加入 `.cpo_uploads/`、`*.log`、`logs/`、`.DS_Store`（已有）
- 核心内容：让代码可回滚、可协作、敏感文件不入库

**② README 补齐：项目地图 + 环境搭建**

这是你最该补的一份。RDS 已 30+ 张表，且**表结构在持续变化**（你 2026-09-04 才刚发现"12 张表"的记忆已过时）。

- 重点标注坑字段：`ad_product`（广告大类，现成）、匹配类型（无字段，需正则解析 campaign_name）、自然单（**禁止倒算**）、`halo_*`/`new_to_brand_*`（高价值但被低估）

### 3.3 分支策略（小团队简化版）

你目前是个人/小团队，**不要照搬 GitFlow**（过度设计）。用简化三分支：

| 分支 | 用途 | 保护规则 |
|------|------|---------|
| `main` | 生产代码，始终可部署 | 禁止直接 push，只能 PR 合入 |
| `develop` | 集成分支 | 禁止直接 push |
| `feature/<短描述>` | 功能开发，如 `feature/cpo-job-state-machine` | 从 develop 拉，合回 develop |
| `fix/<短描述>` | 缺陷修复 | 同上 |

发布时：`develop` → `main`，打 tag。

### 3.4 提交规范（Conventional Commits）

格式：`<type>(<scope>): <subject>`

| type | 场景 |
|------|------|
| `feat` | 新功能 |
| `fix` | 修 bug |
| `docs` | 只改文档 |
| `refactor` | 重构，不改功能 |
| `test` | 测试 |
| `chore` | 构建/依赖/配置 |

示例：
```
feat(cpo): 增加 CPO Job 状态机流转
fix(mapping): 修复产品线映射跨运营串数据
docs(api): 补充错误码与幂等性说明
```

**为什么值得做**：半年后排查问题时，`git log --oneline` 能按类型过滤，比翻"改了点东西"这种提交信息高效十倍。

### 3.5 Issue 与 PR 模板

`.github/ISSUE_TEMPLATE/bug.md`：

### 3.6 Code Review 检查项

即使一个人开发，PR 也是**强制自审**的触发器。检查清单：

- [ ] 是否引入了硬编码配置 / 密钥
- [ ] 错误路径是否都有处理（不是只处理 happy path）
- [ ] 数据库查询是否有 N+1
- [ ] 新增接口是否同步更新了 API 文档
- [ ] 是否有 `console.log` / 调试代码残留
- [ ] 是否删除了无用文件（如 `HelloWorld.vue`）

### 3.7 版本发布

- 语义化版本 `v0.1.0`：主版本.次版本.修订号
- 每次 `develop → main` 打 tag：`git tag -a v0.2.0 -m "..."`
- 维护 `CHANGELOG.md`，按 `Added / Changed / Fixed` 分组

- [ ] 错误提示位置与样式是否一致
- [ ] 表格操作列位置是否固定（排序/导出/下钻）

### 5.3 响应式与可访问性
- [ ] 是否在 1280px 笔记本宽度下可用（后台系统主战场）
- [ ] 表格横向滚动是否可用（字段多时）
- [ ] 颜色是否作为唯一信息载体（红绿之外要有图标/文字，色盲友好）
- [ ] 键盘 Tab 导航是否可达主要操作

### 5.4 视觉规范
- [ ] ❌ **无 UI 组件库 → 间距/圆角/配色全靠手写，必然不一致**（这是"AI 写的样式丑"的根因）

**改进建议**：引入 Naive UI（TS 类型完善、主题系统灵活、设计现代）。核心逻辑——**别让 AI 写 CSS，让它写组件名**。组件库把间距/圆角/色值提前锁死，AI 想丑都难。
