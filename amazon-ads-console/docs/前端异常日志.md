# 前端异常与导航卡住

登录后的控制台安装 Vue 渲染异常、浏览器脚本错误、未处理 Promise 拒绝、脚本/CSS 资源错误及路由错误采集。导航开始后 30 秒仍未完成时记录源页面、目标页面与持续时间；已结束或被新导航替代的计时器不会上报。

所有角色可向 `/api/diagnostics/frontend-errors` 上报本人的异常；账号、角色及运营组由服务端登录态确认。只有超管可查询，入口为“系统诊断 → 前端异常与导航卡住”，支持账号、用户 ID、页面、浏览器版本、错误类型和时间范围筛选。请求日志继续独立展示。

发布时将不可变 Git 提交通过 `VITE_APP_COMMIT` 编入浏览器代码。错误日志同时保留浏览器运行版本和接收服务端版本，避免把仍在旧页面上的客户端误标成新发布版本。

日志只接受固定错误类别和经过限制的资源文件/行列位置，不接收任意异常消息、用户名声明、请求正文、令牌、Cookie、URL 参数或完整报表。前端对相同错误短时去重且每分钟最多 30 条，服务端每用户每进程最多 60 条、单条最大 16 KiB。短时重复 event_id 幂等。日志写入现有共享 JSONL 与系统日志输出，沿用已有轮转；无法写入时返回 503，不谎报已接受。

浏览器上传使用独立原生请求与 5 秒截止时间；上传失败不会递归上报或阻断业务。未登录、离线、标签页已关闭等情况下无法保证上传；没有把敏感业务内容或会话令牌落盘到浏览器。历史上未采集的异常不能补录成真实历史记录。

验收包含真实 Vue/浏览器钩子、计时器替换/结束、错误风暴限流、权限、账号防伪、版本保留、日志落盘和筛选。线上通过本机验收通道对页面模块注入受控故障，使用线上原始前端壳和真实 API 校验采集链路，不在正式页面添加故障按钮，也不修改业务数据。
