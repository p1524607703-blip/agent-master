**关键发现（踩坑）**
1. 业务报告日界是**太平洋时间**（页面快照 GMT-7），不是美东
2. URL 日期区间**左闭右开**：取 D 日单日要传 `fromDate=D&toDate=D+1`
3. 报告页 URL：`#/report?id=102:DetailSalesTrafficByParentItem&fromDate=…&toDate=…`
4. **表格 UI 常渲染不出数据行**（usdCount 恒 0），但「下载 (.csv)」按钮仍产出正确 CSV
   → 就绪判定不能依赖页面数据行
5. kat-* 组件是 shadow DOM 里的 lit 组件；注入 value 能改显示值但点「应用」带不出数据
   → 坚持 URL 驱动
6. 紫鸟代理瞬态 `chromewebdata` 错误 → 先 visit /home 预热 + 重试 3 次
7. 洁博利美站账号**无业务报告访问权限**（广告报告权限是有的，别混淆），已置 `enabled:false`

**日期口径已验算**：北京 9/8 09:00 → 太平洋 9/7 18:00 → 目标 9/6，与用户举例一致。
