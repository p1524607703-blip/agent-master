## node 路径漂移（教训）
- managed node 版本目录后缀会变：`22.22.2-2` → **`22.22.2-3`**（9/3 写死的路径 9/17 已失效）。
- 结论：**不要把 node 绝对路径写死**。已把 automation-1787733100468 改回弹性探测：
  `NODE_BIN="$(command -v node || ls -dt .../versions/*/bin/node | head -1)"`（用 `ls -dt` 按 mtime 取最新，优于原 `head -1` 字典序）。
