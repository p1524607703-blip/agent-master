### 🔴 关键坑：dsh web 由 launchd 守护，不是手动起的
- `~/Library/LaunchAgents/com.panjinlong.deepseek-harness-web.plist`
  - `ProgramArguments` = `/opt/homebrew/bin/pnpm dsh web --no-open`
  - `WorkingDirectory` = 上述仓库；`RunAtLoad=true` + **`KeepAlive=true`** + `ThrottleInterval=5`
  - 日志：`~/Library/Logs/deepseek-harness/web.log` / `web-error.log`（**访问 URL + token 在 web.log 最后一行**）
- 另有 `com.panjinlong.deepseek-harness-tunnel.plist`（跑 `dsh-gpt-mcp-bridge` 的 tunnel-client，profile `deepseek-harness-full`，走 127.0.0.1:6152 代理）。
- ⚠️ **`kill <pid>` 后 launchd 会在 5 秒内自动拉起**；若此时 `pnpm run build` 还没跑完，新进程会加载到"半新"产物并反复启动失败，日志刷一屏 `[ELIFECYCLE] Command failed with exit code 1`。
- ✅ **正确重启姿势**：先 `pkill -f "pnpm dsh web"` 清干净 → 确认 3080 空闲 → **`launchctl kickstart -k gui/$(id -u)/com.panjinlong.deepseek-harness-web`**。
- ⚠️ **不要自己 `nohup pnpm dsh web`**：会和守护进程抢 3080，报 `listen EADDRINUSE`（webserver 是 required 插件，失败即整个启动失败）。
