# Changelog

本项目遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 的结构，并使用 [Semantic Versioning](https://semver.org/lang/zh-CN/)。

## Unreleased

### Added

- 新增专用后台执行工作区：每次运行只在当前 Chrome 窗口创建一个非活动 Amazon 测试标签页，不调用 `chrome.windows.create()`，也不复用、导航或关闭用户正在查看的标签页。
- 新增 `amazon-product-context/v1` 图片工作台桥接链路，可把美国、日本、德国、法国、意大利和西班牙站的商品详情页同步到 `amazon-image-studio`，同时保留 JSON 文件和手动输入方式。
- 建立以 `VERSION` 为唯一事实源的本地版本管理、版本一致性检查和开发日志流程。
- 将开发文档与使用手册拆分为本地事实源和两份固定飞书文档，并增加覆盖同步、回读验证与发布门禁。
- 在开发文档中加入 `smoke`、`calibration`、`full` 三档双轨预设的包含矩阵、精确中英文确定性模板、动态占位符、会话策略和计分边界。

### Changed

- 图片工作台同步改为由用户粘贴的 Amazon PDP 链接锁定站点和 ASIN；扩展只读取已经打开且与链接精确匹配的商品页，不再依据活动页或最近访问顺序猜测目标。
- 侧边栏主流程收敛为唯一的“查看推荐指数”按钮：首次点击自动生成、校验、审核锁定并连续执行全部问题，完成后同一按钮打开报告；预设、人工改题、评分规则和审计日志移入默认折叠的高级区域。
- 商品重新读取改为选择最近使用的 Amazon 商品详情页并支持最后成功快照回退，不再要求用户为了启动测试切回某个前台标签页。
- 鞋类题集升级为 `footwear-v4.1.0`：所有独立题及递进组首题都在正文前声明“仅依据本条需求、不引用或延续先前对话”；独立组继续请求严格鞋类的全体候选与商品链接，递进组保留自然候选、Alexa自定义推荐指数、筛选透明度、无品牌进入假设、场景收窄和标准价格带复评分，仍保持5+6上限且不把模型自评分混入主指数。
- 配置页新增价格带、场景、材料/结构、风险反证和自然用户问法 5 个 AI 建议问题方向，限定只能替换 P4—P6 并要求绑定页面证据。
- 三档预设调整为冒烟 `3+2`、校准 `5+4`、完整 `5+6`，每题只执行一次，不再自动追加品牌/ASIN辅助题。
- 判断标准升级为 `footwear-judgment-v2`；主分强制要求独立新会话，10%一致性维度改为同一意图直接表达与自然语言表达的候选集合Jaccard。
- 报告新增单会话递进轨迹，显示每轮完整候选数、沿用上轮比例和我方商品进出，不把候选变化解释为Amazon内部权重。
- 一键入口检测到仍有待执行题目的旧版题集时会自动重新生成当前 `footwear-v4.1.0` 题集；扩展和服务端也会拒绝直接启动旧 prompt 版本，避免无隔离前缀的旧题被续跑。
- 图片工作台同步优先使用请求来源所在 Chrome 窗口的活动 PDP，否则选择该窗口最近使用的 PDP；只在该窗口没有 PDP 时考虑全局最近的 PDP，全程不激活、导航或创建页面。最后成功快照的回退时限为 15 分钟，已有候选 PDP 抽取失败时还必须与候选 ASIN 一致。

### Fixed

- 修复图片工作台桥接在旧 service worker 或空响应下只显示“Amazon 页面采集失败”的问题；现在会明确提示在 `chrome://extensions` 重新加载扩展，并区分链接无效、目标商品页未打开和页面尚未加载完成。
- 修复 Rufus 尚显示“正在生成回复”就被提前保存为完成，以及独立题刷新 Amazon 首页后仍继承上一题历史的问题。执行器现在识别中英文生成/完成状态、等待回答稳定 3 秒，并在新完成标记、已观察到生成过程或 8 秒兼容等待之后才允许落库；独立题会检查 `Customer question / 客户问题` 与生命周期痕迹，必要时通过 Alexa 面板“更多选项”创建新会话并验证历史已清空。无法证明隔离成功或回答超时时整轮安全停止，不再让污染题进入推荐指数。
- 修复 Rufus 问题已填入后却误点 Amazon 顶部搜索提交按钮，导致测试页导航和异步消息通道关闭的问题；无名 `type=submit` 现在只允许命中 Alexa 输入框所属表单，局部面板与 Shadow DOM 也按输入框作用域查找。消息重试同时改为仅在 Chrome 明确确认“没有接收方”时执行，问题可能已提交时绝不盲目重发；传输异常会保留后台诊断标签页 60 秒。
- 修复运行流程依赖人工确认、人工审批和再次点击开始，导致题集生成后看似不能自动递进的问题；现在一键入口会自动续跑仍有 `pending` 问题的 `ready`、`stopped` 或中断 `running` 运行。
- 彻底移除自动执行器对 `chrome.tabs.get()` 的依赖，解决第一题前反复出现 `No matching signature` 的问题；页面导航改为在动作前注册 `tabs.onUpdated` 监听，截图直接使用已校验的工作区 ID，并在错误中附带执行阶段和构建标识。侧边栏与 service worker 现在会先校验协议和构建版本，旧后台与新界面混跑时会在启动前阻止测试并提示重新加载。
- 修复点击“开始测试”会把当前商品页跳转到 Amazon 首页并导致 Alexa 对话框消失的问题；独立题刷新和新会话现在只发生在当前窗口的非活动后台测试标签页，整个执行过程不会创建新窗口。
- 修复侧边栏切换标签页或关闭后 `Attempting to use a disconnected port object` 会中断整轮运行的问题；侧边栏现在只是监视器，后台会继续自动执行剩余题目。
- 静默后台模式不再调用需要瞬时 `activeTab` 授权的可见页截图，避免误截前台页面或产生权限报错；DOM 回答和完整商品列表仍正常保存。
- 修复 Rufus 发送按钮因可访问名称重复或仅有图标而无法自动点击的问题；执行器现在优先使用 `type=submit`、可访问名称和语义属性定位已启用的提交控件，不再把不可信的模拟回车误判为已发送。
- 修复扩展重载后 Amazon 首页可能从 BFCache 恢复旧 content script 的问题；独立新会话现在强制绕过缓存刷新，并用选择器版本握手确认当前脚本后才开始提问。
- Alexa 回答改为直接读取 DOM，并保存完整可识别商品列表，不再截断为前五名；截图仅作为审计证据并记录失败原因。
- 修复扩展重载或侧边栏断开后运行卡在 `running`、无法继续的问题；现在可以从剩余 `pending` 题恢复，并忽略上一轮迟到的状态消息。
- 修复欢迎页被隐藏 `New chat` 控件误触后找不到 Alexa 输入框的问题；首题可直接使用当前空白会话，后续只点击可见且可用的新会话控件。
- 鞋类问题不再写死推荐 5 款，由 Alexa 自行决定回答数量；Hermes 改写若新增固定结果数量会被拒绝并回退到确定性模板。
- 图片工作台桥接改为专用请求协议并校验 `requestId`；发出扩展前只保留标题、品牌、类目、Bullet、稳定规格和 A+ 正文，移除价格、促销、库存、配送、卖家、评论、评分、Q&A、Rufus/Alexa 对话、账户标签和跟踪参数，避免把零售状态、账号内容或另一 ASIN 的缓存带入图片策划。

## 0.1.0 - 2026-07-16

### Added

- Chrome MV3 侧边栏、Amazon 商品页/Alexa 页面适配器和本地测试状态机。
- NestJS、Prisma/SQLite、Hermes 模型通道、确定性评分与独立报告页。
- 鞋类固定模板、页面证据动态槽位、问题审核锁定、逐轮审计和安全停止机制。
- 英语（Amazon US）与简体中文提问语言。
