## 4. 活动架构诊断

### 四组活动的核心矛盾

**手动Slip on 与自动低价的重叠**：
- 手动Slip on 用 $0.50 竞价广泛匹配 "boys/kids slip on shoes"，自动低价用 $0.08 竞价通过 loose-match/substitutes 也会匹配到 slip on 相关搜索。
- 当用户在搜索 slip on 童鞋时，由于自动低价的出价仅为手动 Slip on 的 1/6，在竞价排名中处于劣势，导致自动低价在核心词上拿不到优质位，只能吃到边角流量（解释了 0.06% CTR）。
- 同时，手动 Slip on 的两个广泛词实际 CPC 分别为 $1.00 和 $1.20，远超 $0.50 竞价——说明这些核心词竞争激烈，竞价过低导致只能靠动态加价去竞争。

**手动barefoot广泛与自动低价的重叠**：
- 手动barefoot广泛用 5 个广泛匹配词覆盖 barefoot/wide shoes 概念，但实际花费的 79% 来自报表外搜索词（因广泛匹配扩展）。
- 这些扩展搜索词很可能与自动低价 loose-match 匹配到的搜索词大量重叠。
- 两者的竞价差（$0.65 vs $0.08）意味着同一个搜索词可能被两个活动不同竞价策略竞拍——形成内部竞价。

**缺失的结构**：
1. **无精确/词组匹配收割活动** — 目前所有手动关键词全部用广泛匹配，没有对已确认的高转化搜索词做精准/词组匹配的高竞价收割。
2. **无品牌词防御活动** — "BRONAX" 品牌搜索没有独立活动。
3. **无长尾高意向词隔离** — 如 "toddler wide toe box shoes"、"kids barefoot sneakers for wide feet" 等购买意图明确的长尾词，混合在广泛匹配中，难以单独调价。
4. **无按匹配类型分层的预算分配** — 广泛发现 → 词组测试 → 精准收割的三层漏斗不完整。

**判断**：当前架构是 "低价广泛铺量 + 两个广泛词碰运气" 的粗放模式。自动低价意外获得了最好的 ACOS，但这不是架构设计的成功，而是在极低竞价下偶然筛出高意向流量的结果。

## 6. 竞价 vs CPC 矛盾分析

### 核心矛盾

**手动Slip on**：竞价 $0.50，实际 CPC $1.00–$1.20，比值 2.0–2.4 倍。建议竞价范围低/中/高分别为 $0.86/$1.23/$1.37。
- **事实**：竞价远低于市场最低建议竞价（$0.86），甚至低于低建议竞价。广告通过 "动态竞价（只降低）" 策略，系统在有转化信号时会加价，但实际 CPC 仍低于市场中间价——说明竞价太低，系统即使加价也达不到理想的展示位置。
- **判断**：这不是最近改过竞价（降低）的表现，而是竞价从一开始就设得太低。动态竞价（只降低）不会将 $0.50 加价到 $1.20——只会降低。因此 **实际 CPC 高于竞价的原因大概率是：广泛匹配下触发到竞争更激烈（CPC 更高）的搜索词，即使以 $0.50 基础价参与拍卖，在这些高竞争词上的成交价自然更高**。
- **不成立的对立假设**：看到 CPC=$1.20 而竞价=$0.50 就判断最近涨过价——这与"只降低"策略矛盾。只降低策略只会从当前竞价向下调整，不会向上。

**手动barefoot广泛**：竞价 $0.65–$0.92，实际 CPC $0.66–$1.29。
- "wide kids sneakers" CPC $1.29，竞价 $0.92 → 超出竞价 40%。策略为"提高和降低"，本身允许系统在转化信号下加价。这个偏离在策略允许范围内。
- "wide shoes toddler" CPC $0.66，竞价 $0.68 → 基本等于竞价，说明这个词竞争适中。

**自动低价**：竞价 $0.08，实际 CPC $0.50–$0.83，比值 6.25–10.4 倍。
- 这是"提高和降低"策略的正常表现。$0.08 是低基准价，系统在有信号时大幅加价。
- **但这引出关键问题**：如果系统通过加价才能拿到流量，说明 $0.08 基准价本身过低。实际成交在 $0.50–$0.83 区间，这是市场的真实价位。应将基准竞价调整到接近这个区间。

### 对预测的影响
- 如果保持当前竞价不动，当前 CPC 水平有持续性（市场供需决定）。
- 如果提高手工 Slip on 竞价至建议低档 $0.86–$1.14，CPC 可能上升但 CTR 和展示位置会改善——不能做线性预测（"竞价翻倍 → 花费翻倍 → 订单翻倍"）。可能的效果是：CTR↑ → 点击↑ → 花费↑ → CVR 可能因更好的位置而改善或恶化（需要 Placement Report 区分首页/商品页/其余位置的 CVR 差异）。

## 8. 盈亏平衡边界

### 不能虚构"盈利 ACOS"

在不知道**单件贡献利润（Contribution Margin per unit）**的情况下，无法计算"盈利的 ACOS 上限"。

**盈亏平衡 ACOS = 广告前贡献利润率（Contribution Margin %）**

公式：
```
盈亏平衡 ACOS = (售价 − 单件变动成本) / 售价 × 100%
```

以当前售价 $29.99 为例：若单件变动成本（货品成本 + FBA 费 + 佣金 + 包装运费）为 $18，则贡献利润 = $11.99，利润率 = 40%，盈亏平衡 ACOS = 40%。

**需要补充的成本字段**：
| 字段 | 用途 |
|------|------|
| 单件货品成本（含头程运费） | 计算毛利 |
| FBA 配送费 / 仓储费 | 变动成本 |
| Amazon 佣金率（童鞋类目通常 15%） | 变动成本 |
| 广告费之外的营销成本（Coupon、Vine 等） | 全口径评估 |
| 退货率及退货成本 | 真实净利润 |

**当前判断边界**：
- 如果这款鞋的贡献利润率 ≥ 65%，那么手动 Slip on 的 ACOS 64.6% 在盈亏平衡线附近。
- 如果贡献利润率 ≥ 97%，手动barefoot广泛的 ACOS 97% 刚好持平。
- 如果贡献利润率仅 30–40%（更现实），那么仅自动低价活动在盈利范围内，手动 Slip on 在严重亏损，手动barefoot广泛在巨亏。

**主动反驳最容易犯的错误**：不能假定 ACOS=17% 就是"盈利"——如果单件利润率仅 15%，那 17% ACOS 也在亏钱。

## 11. 给另一位分析师的质疑清单

> 以下问题假设你正在独立复核本报告，无需认可我的结论。请逐一质疑以下方面：

1. **手动Slip on 的"只降低"策略与 $1.00+ CPC 的矛盾**：报表显示竞价 $0.50、策略"只降低"，但实际 CPC 为 $1.00–$1.20。我只解释了"广泛匹配到高竞争词"这一种可能。你能否排除以下替代解释：(a) 竞价最近从更高值被下调，但 CPC 尚在衰减中？(b) 广告账户有 Portfolio 级别的出价策略覆盖？(c) 某个 Placement 调整乘数（如首页首位 +50%）导致整体 CPC 上浮？需要检查什么数据来排除/确认？

2. **手动barefoot广泛 79% 花费去向未知**：这 $321.79 可能进入了完全无关的搜索词（如 "men's running shoes" 被广泛匹配到），也可能是进入了高转化的长尾词。在没有 Search Term Report 的情况下，你对止损的判断依据是否足够充分？

3. **自动低价 CVR 14.78% 是否被光环订单虚增**：自动低价的 34 个归因订单中，如果大量是光环订单（广告点击 ASIN A 但买了 ASIN B），那么归因逻辑下 CVR 被正确计数。但如果光环订单中有一部分是自然订单被误归因（用户本就打算买、恰好同时点击了广告），CVR 会被高估。你如何排除？

4. **指定广告 ASIN B0D1R1PYGJ 仅 1 单是否异常**：这是新品（listing 创建于 2024 年 4 月？），还是尺码/颜色太偏门（5w Boys Blue Black 可能不是热门 SKU）？需要对比 Business Report 中该 ASIN 的自然销售占比才能判断。

5. **变体池管理 vs 子体管理的利润影响**：虽然光环占比 48.3% 支持按父体管理，但如果各子体的利润率不同（例如 5w 的 FBA 配送费与大尺码不同），按父体统一管理会掩盖子体间的盈利差异。你是否需要按尺码段分组的子体利润率数据？

6. **类目节点 3420717011 零流量的原因**：是因为竞价 $0.20 过低，还是因为这个类目节点与产品不匹配（例如是成人鞋类目而非童鞋），导致系统根本没有匹配到流量？需要验证类目节点描述。

7. **整体 ACOS 48.4% 与盈亏平衡线的距离**：如果你能拿到单件贡献利润数据，请计算 TACOS（广告费/店铺总销售额，含自然流量）。自然流量占比越高，TACOS 越低，对 ACOS 的容忍度就越高。当前自然流量占比未知，你怎么规划广告预算的上限？

8. **Placement Report 的缺失可能导致的方向性误判**：如果 80% 的广告点击发生在商品页面（product page），而商品页面的 CVR 通常远低于搜索首页，那么仅看活动级 CVR 会误判关键词质量。你有办法在没有 Placement Report 的情况下做近似判断吗？

9. **是否应考虑否词策略的溢出风险**：如果你对自动低价添加了否定关键词，而这些否定词恰好是用户在某些搜索路径中的步骤（例如用户搜索 "boys wide shoes" → 发现产品 → 然后搜索 "BRONAX" 购买），否定前者可能中断漏斗上游。你怎么设计否定策略来避免这种风险？

10. **竞价数据报告中动态竞价（只降低）的行为边界**：Amazon 声称"只降低"策略只在转化可能性低时降低出价，但在 $0.50 竞价下实际 CPC 到 $1.00+ 说明竞价根本没有被降低。这是否意味着在广泛匹配中，系统对"转化可能性低"的判断主要基于关键词关联度（相关就是不高也不低），而非基于用户行为信号？如果是这样，"只降低"策略在广泛匹配下是否形同虚设？你是否建议改为"固定竞价"来获得更可预测的 CPC？
