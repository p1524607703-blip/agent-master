一句话结论

DSP 已经是全渠道效率最高的广告产品——27 天花 $4,515、卖 $48,308，ROAS 10.70（站内 SP 只有 3.91），新客订单占比 55.1%。所以问题不再是"要不要投 DSP"，而是"敢不敢把 SP 的钱搬过来"。

搬之前有三件事必须先做：把可见率从 30.8% 修上去、把认知层的预算从 14.4% 提上来、把钱从效率低的那一半挪到效率高的那一半。这三件事的回报都高于追加预算本身。

产品层面的分工是：W8K2 喂算法（信号锚点）、WK101 做面孔（创意主角）、W8K6 做背书（4.7 分全店最高）；W81 守住品牌防御但不再追加；DU08 借 DU03/DU06 的流量池起步。

§ 5 Brand+ 方案：填补认知层

Brand+ 是用第一方信号 + DNN 预测模型找"未来可能对你感兴趣的人"的 AI 方案。在 WHITIN 的账户里，它的任务很明确：去填那个占 14.4% 预算却跑出 ROAS 16.65 的认知层。

5.1 执行顺序（顺序错了，钱就白花）

修可见率

确认 DSP 计费方式是 CPM 还是 vCPM。若为 CPM，改 vCPM；若已是 vCPM，开 pre-bid 品牌安全并屏蔽低质库存。目标：整体 30.8% → 45% 以上。

为什么在最前：在七成展示不可见的情况下投放，等于七成的钱注定打水漂。这一步的回报高于后续所有加预算动作。

调整现有活动结构

砍掉 Clogs · AW · Mules and Clogs · CPDPV（ROAS 2.38 / CPA $10.39）；给 Clogs · AW · All Audiences 加预算（20–30% 步进）；把 Toddler 的再营销占比从 39% 压到 20–25%，腾出的钱转给 Customer Acquisition。

建标准认知层童鞋活动，跑出基线

新建 WHITIN - Toddler - AW - All Audiences - Total Roas，W8K2 + WK101 做创意，预算 $600–800/月。

为什么先建标准版：现有的 Clogs · AW · All Audiences 用标准定向就跑出 ROAS 19.69（日中位数 22.32）。先用同样的标准方法在童鞋上跑出基线，再引入 Brand+ 做 AI 扩量并对照——否则永远分不清是 Brand+ 有用，还是认知层本身有用。

上线 Brand+

预算 $1,500–2,000/月（占现有 DSP 的 30–40%），跑满 4 周后对照上一步的基线。

按纪律加量

单次加幅 ≤20–30%，观察 5–7 天，达标后再加下一档。目标节奏：$5,017/月 → $8,000 → $12,000 → $15,000。

5.4 战略预算与效率预算分开走

  • Toddler 的 P+ 不加预算，只调结构。再营销占比 39% 太高，压到 20–25%

§ 6 站内外 Full-Funnel：四根连接管

"站内外联通"不是口号，是一套有物理连接的管道。站外负责把人从"不知道你"变成"听说过你"，站内负责把"听说过你"变成"下单 + 复购"。连接两段的硬件叫 Amazon Attribution。

6.1 四根连接管

连接物理实现为什么必须做
①Amazon Attribution 标签：按「渠道 = Order、广告组或创意 = Line Item」建标签，挂到所有站外落地点不带标签 = 站外花费完全不可见，且放弃 Brand Referral Bonus 约 10% 返点。服装类目上这 10% 能把站外盈亏平衡 ROAS 从 3.0 拉到 2.73——差的这 0.27 就是"砍掉"和"加投"的区别
②浏览未购池 → 站内再营销：DSP/SD 抓到的 DPV 未购人群，用 SP 精准 + SB 品牌词二次触达站外流量天然冷，一次触达就放弃是最大浪费
③AMC 自定义受众回灌：加购未购、竞品浏览未购、6–12 个月未复购这些受众在 Seller Central 里建不出来，却可直接激活到 SD / DSP。这是 DSP 相对 SP 最不可替代的能力
④跨品 A→B 回路：买过 W8K2 → 推 WK101 / ZK 新码段；买过成人 W81 → 推童鞋WHITIN 有别人没有的结构性优势：码段阶梯 = 天然 LTV 管道。孩子长大换码段不是"复购"是"续杯"，客户没流失，只是在等下一码

§ 7 下钻 SOP：从品牌层到活动级

框架定完之后，真正的钱是在活动级省出来、赚出来的。下面是一条固定的五层下钻路径，每层都有明确的"看什么、决策什么、做什么"。所有 SQL 可直接在 amazon_ads 库上跑。

第 1 层 · 款号层：找预算错配

看曝光份额与 ROAS 排序是否一致。当前几乎完全倒挂。决策：曝光 Top 3 但 ROAS 垫底的减 20–30%；ROAS Top 3 但曝光垫底的每周加 20–30%。

本周动作：W8K7（ROAS 6.79 / 曝光 301K）与 WK101（ROAS 5.21 / 曝光 308K）各加 30%；W81K（CPC $1.12 / CTR 0.28%）减 30%。

-- 款号层：曝光份额 vs 效率排序
SELECT p.canonical_product_code                        AS 款号,
       SUM(c.impressions)                              AS 曝光,
       ROUND(SUM(c.clicks)/NULLIF(SUM(c.impressions),0)*100, 2) AS ctr,
       ROUND(SUM(c.cost)/NULLIF(SUM(c.clicks),0), 2)     AS cpc,
       ROUND(SUM(c.sales)/NULLIF(SUM(c.cost),0), 2)      AS roas,
       ROUND(SUM(c.halo_sales)/NULLIF(SUM(c.sales),0)*100, 1) AS 光环占比
FROM core.subscribed_product_cpo_daily c
JOIN core.product_parent_asin p
  ON p.account_id = c.account_id AND p.parent_asin = c.advertised_product_parent_id
WHERE c.stat_date >= CURRENT_DATE - 90
GROUP BY 1 HAVING SUM(c.cost) > 500
ORDER BY 曝光 DESC;

第 2 层 · 广告类型层：找结构性缺口

看预算占比与 NTB 贡献占比的背离程度。当前 SD 用 4% 拿 28% 的 NTB 单，SP 用 79.3% 拿 2.6%。决策：NTB 贡献显著高于预算占比的类型，每两周加 10–15%。

-- 广告类型层
SELECT ad_product                                     AS 类型,
       ROUND(SUM(spend),0)                            AS 花费,
       ROUND(SUM(spend)::numeric/SUM(SUM(spend)) OVER ()*100,1) AS 预算占比,
       ROUND(SUM(sales)/NULLIF(SUM(spend),0),2)        AS roas,
       SUM(new_to_brand_purchases)                    AS ntb单
FROM core.campaign_daily
WHERE stat_date >= CURRENT_DATE - 90
GROUP BY 1 ORDER BY 花费 DESC;

第 3 层 · 产品线 / 运营组层：找组织级差异

product_line 带运营组前缀（ZJ1 = 刘子娟+刘贞珍、XH1 = 阴鑫华、YT1 = 林雅婷、DD1 / LB1 / XM1 / XM2）。决策：同款不同组 ROAS 差 > 30% 的，把高效组的结构复制给低效组。

当前读数：ZJ1-W8K2 ROAS 5.36 / XH1-W8K6 4.86 / XH1-W81K 3.85。另 XM1-Y10 花 $265,175 却只有 ROAS 2.65，占全店花费 10.8%，值得单独开会。

-- 产品线层
SELECT product_line, ROUND(SUM(spend),0) AS 花费, ROUND(SUM(sales),0) AS 销售额,
       ROUND(SUM(sales)/NULLIF(SUM(spend),0),2) AS roas
FROM core.campaign_daily
WHERE stat_date >= CURRENT_DATE - 60
  AND product_line ~ 'W8K2|W8K6|WK101|W81|W8K7|DU0'
GROUP BY 1 HAVING SUM(spend) > 1000 ORDER BY 花费 DESC;

第 5 层 · 时段 / 广告位层

库里有 campaign_hourly 与 campaign_placement_daily。回答两个问题：一天里哪些小时在烧钱不产出、哪个广告位在做无用功。决策：连续 2 周某时段 CVR 显著低于日均且花费占比 > 10% → 降价或停投；广告位 CVR 差 > 2 倍 → 用广告位竞价调整。

-- 时段层
SELECT EXTRACT(HOUR FROM h.hour) AS 时, ROUND(SUM(h.spend),0) AS 花费,
       ROUND(SUM(h.sales)/NULLIF(SUM(h.spend),0),2) AS roas,
       ROUND(SUM(h.purchases)/NULLIF(SUM(h.clicks),0)*100,1) AS cvr
FROM core.campaign_hourly h
WHERE h.stat_date >= CURRENT_DATE - 30
GROUP BY 1 ORDER BY 1;

三条判据

何时砍掉 DSP

跑满 8 周，DPVR < 0.3% 且品牌搜索量零增长。触达到了但没人记住你，才是真的没救。

何时暂停加量

频次 > 8 次/周且 eCPM 开始上涨。此时应扩受众，而不是加预算。

何时加大投入

TACoS 下降 + 品牌搜索量上升 + SP 的 CPC 稳住三者同时出现，说明品牌广告真的在降低整体获客成本。

提前说明：2026 年归因规则变更 Amazon 已把 Sponsored Brands / Display / DSP 的 view-through 归因改为 shopping-signal enhanced last-touch——只有"看过广告 + 有购物行为信号"才计转化。你会在报表上看到 DSP 和 SD 的 ROAS 掉一截，不是广告失效，是口径收紧。请提前与所有看报表的人对齐，并统一改用长期 ROAS 作为 DSP 主指标（长期比即时高 25–34%）。
